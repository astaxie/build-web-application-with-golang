# 3 Web temelleri

Bu kitabı okuyor olmanızın sebebi, Go ile web uygulamaları geliştirmeyi öğrenmek istemenizdir. Daha önce de söylediğim gibi, Go `http` gibi birçok güçlü paket sunuyor. Bu paketler, web uygulamaları geliştirmeye çalışırken size çok yardımcı olacaktır. İlerleyen bölümlerde bilmeniz gereken her şeyi anlatacağım. Bu bölümde ise web'e dair bazı kavramlardan ve Go'da web uygulamalarının nasıl çalıştırıldığından bahsedeceğiz.

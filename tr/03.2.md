# 3.2 Basit bir web sunucu oluşturma

Web uygulamalarının HTTP protokolü üzerine kurulu olduğunu konuşmuştuk ve Go, `net/http` paketinde tam HTTP desteği sunuyor. Bu paketi kullanarak bir web sunucusunu ayağa kaldırmak çok kolaydır.

## http paketiyle bir web sunucusu kurmak

```go
	package main

	import (
    	"fmt"
    	"net/http"
    	"strings"
    	"log"
	)

	func sayhelloName(w http.ResponseWriter, r *http.Request) {
    	r.ParseForm()  // argümanları ayrıştır, bunu kendiniz çağırmanız gerekiyor
    	fmt.Println(r.Form)  // form bilgisini sunucu tarafında yazdır
    	fmt.Println("path", r.URL.Path)
    	fmt.Println("scheme", r.URL.Scheme)
    	fmt.Println(r.Form["url_long"])
    	for k, v := range r.Form {
        	fmt.Println("key:", k)
        	fmt.Println("val:", strings.Join(v, ""))
    	}
    	fmt.Fprintf(w, "Merhaba astaxie!") // veriyi istemci tarafına gönder
	}

	func main() {
    	http.HandleFunc("/", sayhelloName) // yönlendiriciyi ayarla
    	err := http.ListenAndServe(":9090", nil) // dinlenecek portu ayarla
    	if err != nil {
        	log.Fatal("ListenAndServe: ", err)
    	}
	}
```
	
Yukarıdaki kodu çalıştırdıktan sonra sunucu, yerel makinede 9090 portunu dinlemeye başlar.

Tarayıcınızı açın ve `http://localhost:9090` adresini ziyaret edin. Ekranınızda `Merhaba astaxie` yazdığını görebilirsiniz.

Şimdi de ek argümanlar içeren başka bir adresi deneyelim: `http://localhost:9090/?url_long=111&url_long=222`

Bakalım hem istemci hem de sunucu tarafında neler oluyor.

Şekil 3.8 Sunucunun yazdırdığı bilgiler

Gördüğünüz gibi, basit bir web sunucusu oluşturmak için sadece iki fonksiyon çağırmamız yeterli.

PHP ile çalışıyorsanız muhtemelen Nginx ya da Apache gibi bir şeye ihtiyacımız olup olmadığını soruyorsunuzdur. Cevap hayır, ihtiyacımız yok; çünkü Go, TCP portunu kendisi dinliyor ve `sayhelloName` fonksiyonu da tıpkı PHP'deki bir controller gibi mantığı barındıran fonksiyondur.

Python ile çalışıyorsanız tornado'yu biliyor olmalısınız; yukarıdaki örnek ona çok benziyor.

Ruby ile çalışıyorsanız bunun ROR'daki (Ruby on Rails) script/server'a benzediğini fark edebilirsiniz.

Bu bölümde basit bir web sunucusu kurmak için iki basit fonksiyon kullandık ve bu basit sunucu şimdiden yüksek eşzamanlılık gerektiren işlemleri kaldıracak kapasiteye sahip. Bunu nasıl kullanacağımızı sonraki iki bölümde konuşacağız.

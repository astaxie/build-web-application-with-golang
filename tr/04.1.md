# 4.1 Form girdilerini işleme

Başlamadan önce, tipik bir kullanıcı formunun basit bir örneğine göz atalım; bu dosyayı proje dizininize `login.gtpl` adıyla kaydedin.
```html
<html>
	<head>
	<title></title>
	</head>
	<body>
		<form action="/login" method="post">
			Kullanıcı adı:<input type="text" name="username">
			Şifre:<input type="password" name="password">
			<input type="submit" value="Giriş">
		</form>
	</body>
</html>
```
Bu form, sunucudaki `/login` adresine gönderim yapacak. Kullanıcı giriş butonuna tıkladıktan sonra veri, sunucunun yönlendiricisine kayıtlı `login` handler'ına iletilecek. Sonrasında ise bu isteğin POST methodunu mu yoksa GET'i mi kullandığını bilmemiz gerekiyor.

`http` paketini kullanarak bunu öğrenmek çok kolay. Giriş sayfasındaki form verisini nasıl işleyeceğimize bakalım.

```Go
package main

import (
	"fmt"
	"html/template"
	"log"
	"net/http"
	"strings"
)

func sayhelloName(w http.ResponseWriter, r *http.Request) {
	r.ParseForm() //Gönderilen url parametrelerini ayrıştırır, ardından POST gövdesi (request body) için yanıt paketini ayrıştırır
	// dikkat: ParseForm methodunu çağırmazsanız, aşağıdaki form verilerini elde edemezsiniz
	fmt.Println(r.Form) // bilgiyi sunucu tarafında yazdır.
	fmt.Println("path", r.URL.Path)
	fmt.Println("scheme", r.URL.Scheme)
	fmt.Println(r.Form["url_long"])
	for k, v := range r.Form {
		fmt.Println("key:", k)
		fmt.Println("val:", strings.Join(v, ""))
	}
	fmt.Fprintf(w, "Merhaba astaxie!") // veriyi yanıta yaz
}

func login(w http.ResponseWriter, r *http.Request) {
	fmt.Println("method:", r.Method) //istek methodunu al
	if r.Method == "GET" {
		t, _ := template.ParseFiles("login.gtpl")
		t.Execute(w, nil)
	} else {
		r.ParseForm()
		// giriş işleminin mantık kısmı
		fmt.Println("kullanıcı adı:", r.Form["username"])
		fmt.Println("şifre:", r.Form["password"])
	}
}

func main() {
	http.HandleFunc("/", sayhelloName) // yönlendirici kuralını ayarla
	http.HandleFunc("/login", login)
	err := http.ListenAndServe(":9090", nil) // dinlenecek portu ayarla
	if err != nil {
		log.Fatal("ListenAndServe: ", err)
	}
}

```
Burada istek methodunu almak için `r.Method` kullanıyoruz; bu da bize "GET", "POST", "PUT" gibi bir http fiili döndürür.

`login` fonksiyonunda, isteğin giriş sayfası mı yoksa giriş işleme mantığı mı olduğunu anlamak için `r.Method` kullanıyoruz. Başka bir deyişle, kullanıcının sayfayı yalnızca açıp açmadığını yoksa giriş yapmaya mı çalıştığını kontrol ediyoruz. Sunucu, istek GET methoduyla geldiğinde sadece sayfayı gösterir; istek POST methodunu kullandığında ise giriş mantığını çalıştırır.

Şekil 4.1 Kullanıcı giriş arayüzü

Bir kullanıcı adı ve şifre yazana kadar sunucu hiçbir şey yazdırmayacaktır, çünkü handler, biz `r.ParseForm()`'u çağırana kadar formu ayrıştırmaz. `fmt.Println("kullanıcı adı:", r.Form["username"])` satırından önce `r.ParseForm()` ekleyelim, programımızı derleyip tekrar deneyelim. Bilgilerin artık sunucu tarafında yazdırıldığını göreceksiniz.

`r.Form`, isteğe ait tüm argümanları içerir; örneğin URL'deki query-string ile POST ve PUT içindeki veriler. Veriler çakışırsa, örneğin aynı ada sahip parametreler varsa, sunucu bu verileri birden fazla değer taşıyan bir `slice` içinde saklar. Go dokümantasyonu, Go'nun GET ve POST isteklerinden gelen veriyi farklı yerlerde saklayacağını belirtir.

`login.gtpl` dosyasındaki formun action değerini `http://127.0.0.1:9090/login` yerine `http://127.0.0.1:9090/login?username=astaxie` olarak değiştirmeyi deneyin, tekrar test edin; `slice`'ın sunucu tarafında yazdırıldığını göreceksiniz.

![](images/4.1.slice.png?raw=true)

Şekil 4.2 Sunucu, istek verisini yazdırıyor

`request.Form`'un türü `url.Values`'tır. Veriyi `key=value` biçiminde saklar.
```Go
	v := url.Values{}
	v.Set("name", "Ava")
	v.Add("friend", "Jess")
	v.Add("friend", "Sarah")
	v.Add("friend", "Zoe")
	// v.Encode() == "name=Ava&friend=Jess&friend=Sarah&friend=Zoe"
	fmt.Println(v.Get("name"))
	fmt.Println(v.Get("friend"))
	fmt.Println(v["friend"])
```
**İpucu** İstekler, form verisine `FormValue()` methodunu kullanarak da erişebilir. Örneğin `r.Form["username"]` yerine `r.FormValue("username")` yazabilirsiniz; Go, `r.ParseForm`'u otomatik olarak çağırır. Aynı ada sahip argümanlar varsa ilk değerin döndüğüne, böyle bir argüman yoksa boş bir string döndüğüne dikkat edin.

# 4.2 Girdilerin doğrulanması

Web geliştirmedeki en önemli ilkelerden biri, istemci tarafındaki kullanıcı formlarından gelen hiçbir şeye güvenemeyeceğinizdir. Gelen tüm veriyi kullanmadan önce doğrulamanız gerekir. Basit ama bir o kadar da hayati olan bu sorun pek çok web sitesini etkilemektedir.

Form verisini doğrulamanın yaygın olarak kullanılan iki yolu vardır. Birincisi ön yüzde (front-end) JavaScript ile doğrulama, ikincisi ise arka yüzde (back-end) sunucu doğrulamasıdır. Bu bölümde, web geliştirmede sunucu tarafındaki doğrulamadan bahsedeceğiz.

## Zorunlu alanlar

Bazen kullanıcıların bazı alanları doldurmasını isteriz ama onlar bu alanı boş bırakır. Örneğin bir önceki bölümde kullanıcı adı istemiştik. Kullanıcıların gerçekten bir şey girdiğinden emin olmak için bir alanın uzunluğunu `len` fonksiyonuyla alabilirsiniz.
```Go
	if len(r.Form["username"][0])==0{
    	// boş alan için kod
	}
```
`r.Form`, boş bırakılan form öğelerine türlerine göre farklı davranır. Boş metin kutuları, metin alanları ve dosya yüklemeleri için boş bir string döner; radyo düğmeleri ve onay kutuları içinse ilgili öğeleri hiç oluşturmaz. Bunun yerine, erişmeye çalışırsanız hata alırsınız. Bu yüzden alan değerlerini almak için `r.Form.Get()` kullanmak daha güvenlidir; çünkü değer mevcut değilse her zaman boş döner. Öte yandan `r.Form.Get()` bir seferde yalnızca bir alan değeri alabilir, dolayısıyla değerlerin map'ini almak için `r.Form` kullanmanız gerekir.

## Sayılar

Bazen alan değeri olarak metin değil sayı istersiniz. Örneğin, bir kullanıcının yaşını "yeterince yaşlı" ya da "genç adam" gibi ifadelerle değil, yalnızca tam sayı biçiminde, yani 50 ya da 10 olarak istediğinizi düşünelim. Pozitif bir sayı istiyorsak, değeri önce `int` türüne çevirip sonra işleyebiliriz.
```Go
	getint,err:=strconv.Atoi(r.Form.Get("age"))
	if err!=nil{
    	// sayıya çevirirken hata oluştu, sayı olmayabilir
	}

	// sayının aralığını kontrol et
	if getint >100 {
    	// çok büyük
	}
```
Bunu yapmanın bir başka yolu da düzenli ifadeler (regular expression) kullanmaktır.
```Go
	if m, _ := regexp.MatchString("^[0-9]+$", r.Form.Get("age")); !m {
    	return false
	}
```	
Yüksek performans söz konusu olduğunda düzenli ifadeler verimli değildir, ancak basit düzenli ifadeler genellikle yeterince hızlıdır. Düzenli ifadelere aşinaysanız, bu veriyi doğrulamanın çok kullanışlı bir yoludur. Go'nun [RE2](http://code.google.com/p/re2/wiki/Syntax) kullandığını, dolayısıyla tüm UTF-8 karakterlerinin desteklendiğini unutmayın.

## Çince

Bazen kullanıcıların Çince adlarını girmelerini isteriz ve hepsinin rastgele karakterler yerine gerçekten Çince kullandığını doğrulamamız gerekir. Çince doğrulaması için tek yol düzenli ifadelerdir.
```Go
if m, _ := regexp.MatchString("^[\\x{4e00}-\\x{9fa5}]+$", r.Form.Get("realname")); !m {
	return false
}
```
## İngilizce harfler

Bazen kullanıcıların yalnızca İngilizce harf girmesini isteriz. Örneğin, birinin İngilizce adını isteriz; asta谢 değil astaxie gibi. Doğrulamamızı yapmak için kolayca düzenli ifade kullanabiliriz.
```Go
if m, _ := regexp.MatchString("^[a-zA-Z]+$", r.Form.Get("engname")); !m {
	return false
}
```
## E-posta adresi

Kullanıcıların geçerli bir e-posta adresi girip girmediğini bilmek istiyorsanız, aşağıdaki düzenli ifadeyi kullanabilirsiniz:
```Go
	if m, _ := regexp.MatchString(`^([\w\.\_]{2,10})@(\w{1,}).([a-z]{2,4})$`, r.Form.Get("email")); !m {
    	fmt.Println("hayır")
	}else{
    	fmt.Println("evet")
	}
```
## Açılır liste

Diyelim ki açılır listemizden bir öğe seçilmesini istiyoruz, ama bunun yerine hacker'ların uydurduğu bir değer geliyor. Bunun olmasını nasıl engelleriz?

Elimizde aşağıdaki `<select>` olduğunu varsayalım:
```html
	<select name="fruit">
	<option value="apple">apple</option>
	<option value="pear">pear</option>
	<option value="banana">banana</option>
	</select>
```
Girdimizi temizlemek için aşağıdaki stratejiyi kullanabiliriz:
```Go
	slice:=[]string{"apple","pear","banana"}

	for _, v := range slice {
    	if v == r.Form.Get("fruit") {
        	return true
    	}
	}
	return false
```
Yukarıda gösterdiğim bütün fonksiyonlar, slice'lar ve map'ler üzerinde işlem yapmak için yazdığım açık kaynaklı projemin içinde yer alıyor: [https://github.com/astaxie/beeku](https://github.com/astaxie/beeku)

## Radyo düğmeleri

Kullanıcının erkek mi kadın mı olduğunu bilmek istiyorsak, erkek için 1, kadın için 2 dönen bir radyo düğmesi kullanabiliriz. Ancak HTTP üzerine ilk kitabını yeni okumuş küçük bir çocuk size 3 göndermeye karar verir. Programınız exception fırlatacak mı? Gördüğünüz gibi, radyo düğmemizden yalnızca beklenen değerlerin döndüğünden emin olmak için açılır liste için kullandığımız yöntemin aynısını kullanmamız gerekiyor.
```html
	<input type="radio" name="gender" value="1">Male
	<input type="radio" name="gender" value="2">Female
```
Girdiyi doğrulamak için de aşağıdaki kodu kullanıyoruz:
```Go
	slice:=[]string{"1","2"}

	for _, v := range slice {
    	if v == r.Form.Get("gender") {
        	return true
    	}
	}
	return false
```
## Onay kutuları

Kullanıcı ilgi alanları için bazı onay kutuları olduğunu ve burada da fazladan değerler istemediğinizi varsayalım. Bunları şu şekilde doğrulayabilirsiniz:
```html
	<input type="checkbox" name="interest" value="football">Football
	<input type="checkbox" name="interest" value="basketball">Basketball
	<input type="checkbox" name="interest" value="tennis">Tennis
```
Bu durumda temizleme işlemi, düğme ve onay kutusu girdilerini doğrulamaktan biraz farklıdır; çünkü burada onay kutularından bir slice elde ediyoruz.
```Go
slice:=[]string{"football","basketball","tennis"}
a:=Slice_diff(r.Form["interest"],slice)
if a == nil{
	return true
}

return false 
```
## Tarih ve saat

Kullanıcıların geçerli bir tarih ya da saat girmesini istediğinizi varsayalım. Go'da yılı, ayı ve günü karşılık gelen zamanlara çevirmek için `time` paketi vardır. Bundan sonra kontrol etmek kolaydır.
```Go
	t := time.Date(2009, time.November, 10, 23, 0, 0, 0, time.UTC)
	fmt.Printf("Go %s tarihinde yayınlandı\n", t.Local())
```
Zamanı elde ettikten sonra, ihtiyacınıza göre daha fazla işlem için `time` paketini kullanabilirsiniz.

Bu bölümde, sunucu tarafında form verisini doğrulamanın bazı yaygın yöntemlerini ele aldık. Umarım artık Go'da veri doğrulama konusunda, özellikle de düzenli ifadeleri lehinize nasıl kullanacağınız konusunda daha çok şey biliyorsunuzdur.

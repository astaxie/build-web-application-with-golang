# 4.3 Cross site scripting

Günümüzün web siteleri, kullanıcı deneyimini iyileştirmek için çok daha fazla dinamik içerik barındırıyor. Bu da her kullanıcının davranışına göre dinamik bilgi sunmamız gerektiği anlamına geliyor. Ne yazık ki dinamik web siteleri, "Cross site scripting" ("XSS" olarak da bilinir) adı verilen kötü niyetli saldırılara açıktır. Statik web siteleri ise Cross site scripting'e açık değildir.

Saldırganlar çoğu zaman JavaScript, VBScript, ActiveX ya da Flash gibi kötü niyetli scriptleri açık barındıran sitelere enjekte ederler. Scriptlerini bir kez başarıyla enjekte ettiklerinde kullanıcı bilgileri çalınabilir ve siteniz spam ile dolup taşabilir. Saldırganlar ayrıca kullanıcı ayarlarını istedikleri gibi değiştirebilirler.

Bu tür bir saldırıyı engellemek istiyorsanız aşağıdaki iki yaklaşımı bir arada uygulamalısınız:

- Kullanıcıdan gelen tüm verilerin doğrulanması; bunu bir önceki bölümde ele almıştık.
- Enjekte edilmiş scriptlerin tarayıcılarda çalışmasını engellemek için istemcilere gönderilecek verilerin dikkatle işlenmesi.

Peki bu iki işi Go'da nasıl yapabiliriz? Neyse ki `html/template` paketinde, veriyi escape etmek için işinize yarayacak şu fonksiyonlar bulunur:

- `func HTMLEscape(w io.Writer, b []byte)` b'yi escape ederek w'ye yazar.
- `func HTMLEscapeString(s string) string` s'yi escape ettikten sonra oluşan string'i döndürür.
- `func HTMLEscaper(args ...interface{}) string` birden fazla argümanı escape ettikten sonra oluşan string'i döndürür.

4.1 bölümündeki örneği değiştirelim:
```Go
	fmt.Println("kullanıcı adı:", template.HTMLEscapeString(r.Form.Get("username"))) // sunucu tarafında ekrana bas
	fmt.Println("şifre:", template.HTMLEscapeString(r.Form.Get("password")))
	template.HTMLEscape(w, []byte(r.Form.Get("username"))) // istemcilere gönderilen cevap
```

Şekil 4.3 Escape edildikten sonraki JavaScript

`html/template` paketindeki fonksiyonlar bütün HTML etiketlerini escape etmenize yardımcı olur. Peki tarayıcılara sadece `<script>alert()</script>` yazdırmak isterseniz ne olacak? Bu durumda onun yerine `text/template` paketini kullanmalısınız.
```Go
	import "text/template"
	...
	t, err := template.New("foo").Parse(`{{define "T"}}Merhaba, {{.}}!{{end}}`)
	err = t.ExecuteTemplate(out, "T", "<script>alert('you have been pwned')</script>")
```
Çıktı:
```html
Merhaba, <script>alert('you have been pwned')</script>!
```
Ya da `template.HTML` türünü kullanabilirsiniz:
Türü `template.HTML` olan bir değişkenin içeriği escape edilmez.
```Go
	import "html/template"
	...
	t, err := template.New("foo").Parse(`{{define "T"}}Merhaba, {{.}}!{{end}}`)
	err = t.ExecuteTemplate(out, "T", template.HTML("<script>alert('you have been pwned')</script>"))
```
Çıktı:
```html
Merhaba, <script>alert('you have been pwned')</script>!
```
Escape işlemine bir örnek daha:
```Go
	import "html/template"
	...
	t, err := template.New("foo").Parse(`{{define "T"}}Merhaba, {{.}}!{{end}}`)
	err = t.ExecuteTemplate(out, "T", "<script>alert('you have been pwned')</script>")
```
Çıktı:
```html
Merhaba, &lt;script&gt;alert(&#39;you have been pwned&#39;)&lt;/script&gt;!
```

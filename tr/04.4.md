# 4.4 Duplicate submissions

Bazı bloglarda ya da forumlarda (BBS) tıpatıp aynı olan birden fazla gönderi gördünüz mü bilmiyorum, ama size şunu söyleyebilirim: bunun sebebi, kullanıcıların aynı gönderi formunu birden fazla kez göndermesidir. Mükerrer gönderime (duplicate submission) yol açabilecek pek çok şey vardır; kimi zaman kullanıcılar gönder düğmesine çift tıklar, kimi zaman da gönderdikten sonra içeriğin bir kısmını değiştirmek isteyip geri düğmesine basar. Bazı durumlarda ise bu, kötü niyetli kullanıcıların bilinçli davranışlarından kaynaklanır. Mükerrer gönderimlerin ne kadar çok soruna yol açabileceğini görmek zor değil. Bu yüzden bunu önlemek için etkili yöntemler kullanmalıyız.

Çözüm, formunuza benzersiz bir token taşıyan gizli bir alan eklemek ve gelen veriyi işlemeden önce bu token'ı her zaman kontrol etmektir. Ayrıca, bir formu göndermek için Ajax kullanıyorsanız, form bir kez gönderildikten sonra gönder düğmesini JavaScript ile devre dışı bırakın.

4.2 bölümündeki örneği geliştirelim:
```html
	<input type="checkbox" name="interest" value="football">Futbol
	<input type="checkbox" name="interest" value="basketball">Basketbol
	<input type="checkbox" name="interest" value="tennis">Tenis
	Kullanıcı adı:<input type="text" name="username">
	Şifre:<input type="password" name="password">
	<input type="hidden" name="token" value="{{.}}">
	<input type="submit" value="Giriş">
```
Token'ı üretmek için bir MD5 hash'i (zaman damgası) kullanıyoruz ve bunu hem istemci tarafındaki formun gizli alanına hem de sunucu tarafındaki oturum çerezine (session cookie) ekliyoruz (6. bölüm). Ardından bu token'ı, formun gönderilip gönderilmediğini kontrol etmek için kullanabiliriz.
```Go
func login(w http.ResponseWriter, r *http.Request) {
	fmt.Println("method:", r.Method) // istek methodunu al
	if r.Method == "GET" {
		crutime := time.Now().Unix()
		h := md5.New()
		io.WriteString(h, strconv.FormatInt(crutime, 10))
		token := fmt.Sprintf("%x", h.Sum(nil))

		t, _ := template.ParseFiles("login.gtpl")
		t.Execute(w, token)
	} else {
		// giriş isteği
		r.ParseForm()
		token := r.Form.Get("token")
		if token != "" {
			// token'ın geçerliliğini kontrol et
		} else {
			// token yoksa hata ver
		}
		fmt.Println("kullanıcı adı uzunluğu:", len(r.Form["username"][0]))
		fmt.Println("kullanıcı adı:", template.HTMLEscapeString(r.Form.Get("username"))) // sunucu tarafında yazdır
		fmt.Println("şifre:", template.HTMLEscapeString(r.Form.Get("password")))
		template.HTMLEscape(w, []byte(r.Form.Get("username"))) // istemciye cevap ver
	}
}

```

Şekil 4.4 Token eklendikten sonra tarayıcıdaki içerik

Bu sayfayı yenileyebilirsiniz; her seferinde farklı bir token göreceksiniz. Bu da her formun benzersiz olmasını sağlar.

Şimdilik, formlarınıza token ekleyerek mükerrer gönderim saldırılarının birçoğunu engelleyebilirsiniz; fakat bu yöntem, bu türden aldatıcı saldırıların tamamını engelleyemez. Yapılması gereken çok daha fazla iş var.

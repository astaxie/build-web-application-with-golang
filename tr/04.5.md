# 4.5 Dosya yükleme

Diyelim ki Instagram gibi bir siteniz var ve kullanıcıların güzel fotoğraflarını yüklemesini istiyorsunuz. Bu işlevi nasıl gerçekleştirirdiniz?

Fotoğraf yüklemek için kullanacağınız forma `enctype` özelliğini eklemeniz gerekir. Bu özelliğin alabileceği üç değer vardır:

```
application/x-www-form-urlencoded   Yüklemeden önce tüm karakterleri dönüştürür (öntanımlı).
multipart/form-data   Dönüştürme yapmaz. Formunuzda dosya yükleme alanları varsa bu değeri kullanmalısınız.
text/plain    Boşlukları "+" işaretine çevirir, ancak özel karakterler için dönüştürme yapmaz.
```


Bu nedenle, bir dosya yükleme formunun HTML içeriği şöyle olmalıdır:

```html
<html>
<head>
   	<title>Dosya yükle</title>
</head>
<body>
<form enctype="multipart/form-data" action="http://127.0.0.1:9090/upload" method="post">
	<input type="file" name="uploadfile" />
	<input type="hidden" name="token" value="{{.}}"/>
	<input type="submit" value="yükle" />
</form>
</body>
</html>
```


Bu formu işlemek için sunucu tarafına bir fonksiyon eklememiz gerekiyor.

```Go
http.HandleFunc("/upload", upload)

// yükleme mantığı
func upload(w http.ResponseWriter, r *http.Request) {
   	fmt.Println("method:", r.Method)
   	if r.Method == "GET" {
       	crutime := time.Now().Unix()
       	h := md5.New()
       	io.WriteString(h, strconv.FormatInt(crutime, 10))
       	token := fmt.Sprintf("%x", h.Sum(nil))

       	t, _ := template.ParseFiles("upload.gtpl")
       	t.Execute(w, token)
   	} else {
       	r.ParseMultipartForm(32 << 20)
       	file, handler, err := r.FormFile("uploadfile")
       	if err != nil {
           	fmt.Println(err)
           	return
       	}
       	defer file.Close()
       	fmt.Fprintf(w, "%v", handler.Header)
       	f, err := os.OpenFile("./test/"+handler.Filename, os.O_WRONLY|os.O_CREATE, 0666)
       	if err != nil {
           	fmt.Println(err)
           	return
       	}
       	defer f.Close()
       	io.Copy(f, file)
   	}
}
```


Gördüğünüz gibi, dosya yüklemek için `r.ParseMultipartForm` fonksiyonunu çağırmamız gerekiyor. ParseMultipartForm fonksiyonu `maxMemory` argümanını alır. `ParseMultipartForm`'u çağırdıktan sonra dosya, sunucunun belleğinde `maxMemory` boyutu kadar saklanır. Dosyanın boyutu `maxMemory`'den büyükse, verinin geri kalanı geçici bir sistem dosyasına kaydedilir. Dosya tanıtıcısını almak için `r.FormFile`, dosya sisteminize kaydetmek için de `io.Copy` fonksiyonunu kullanabilirsiniz.

Formdaki dosya olmayan diğer alanlara erişirken `r.ParseForm` fonksiyonunu çağırmanıza gerek yoktur, çünkü Go gerektiğinde bunu kendisi çağırır. Ayrıca `ParseMultipartForm`'u bir kez çağırmak yeterlidir; birden fazla çağrının bir etkisi olmaz.

Dosya yüklemek için şu üç adımı izliyoruz:

1. Formunuza `enctype="multipart/form-data"` özelliğini ekleyin.
2. Dosyayı belleğe ya da geçici bir dosyaya kaydetmek için sunucu tarafında `r.ParseMultipartForm` fonksiyonunu çağırın.
3. Dosya tanıtıcısını almak ve dosya sistemine kaydetmek için `r.FormFile` fonksiyonunu çağırın.

Dosya tanıtıcısı `multipart.FileHeader`'dır. Aşağıdaki struct'ı kullanır:

```Go
type FileHeader struct {
   	Filename string
   	Header   textproto.MIMEHeader
   	// filtrelenmiş ya da dışa aktarılmamış alanları içerir
}
```

## İstemcilerin dosya yüklemesi

Dosya yüklemek için bir form kullanmayı örnekle gösterdim. Go'da da bir istemci formunu taklit ederek dosya yükleyebiliriz.

```Go
package main

import (
    "bytes"
    "fmt"
    "io"
    "io/ioutil"
    "mime/multipart"
    "net/http"
    "os"
)

func postFile(filename string, targetUrl string) error {
    bodyBuf := &bytes.Buffer{}
    bodyWriter := multipart.NewWriter(bodyBuf)

    // bu adım çok önemli
    fileWriter, err := bodyWriter.CreateFormFile("uploadfile", filename)
    if err != nil {
        fmt.Println("tampona yazarken hata oluştu")
        return err
    }

    // dosya tanıtıcısını aç
    fh, err := os.Open(filename)
    if err != nil {
        fmt.Println("dosya açılırken hata oluştu")
        return err
    }
    defer fh.Close()

    //iocopy
    _, err = io.Copy(fileWriter, fh)
    if err != nil {
        return err
    }

    contentType := bodyWriter.FormDataContentType()
    bodyWriter.Close()

    resp, err := http.Post(targetUrl, contentType, bodyBuf)
    if err != nil {
        return err
    }
    defer resp.Body.Close()
    resp_body, err := ioutil.ReadAll(resp.Body)
    if err != nil {
        return err
    }
    fmt.Println(resp.Status)
    fmt.Println(string(resp_body))
    return nil
}

// örnek kullanım
func main() {
    target_url := "http://localhost:9090/upload"
    filename := "./astaxie.pdf"
    postFile(filename, target_url)
}
```


Yukarıdaki örnek, dosya yüklemek için bir istemcinin nasıl kullanılacağını gösteriyor. Dosyaları önbelleğe yazmak için `multipart.Write` kullanıyor ve POST methodu ile sunucuya gönderiyor.

Veriye yazılması gereken kullanıcı adı gibi başka alanlarınız varsa, gerektiğinde `multipart.WriteField` fonksiyonunu çağırın.

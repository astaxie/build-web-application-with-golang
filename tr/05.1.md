# 5.1 database/sql arayüzü

PHP gibi bunu yapan diğer dillerin aksine Go, resmî bir veritabanı sürücüsü sunmaz. Buna karşılık, geliştiricilerin veritabanı sürücüsü geliştirebilmesi için bazı veritabanı sürücü interface (arayüz) standartları içerir. Bunun avantajı şudur: Kodunuzu bu interface standartlarına göre geliştirirseniz, veritabanınız değiştiğinde hiçbir kodu değiştirmeniz gerekmez. Gelin bu veritabanı interface standartlarının neler olduğuna bakalım.

## sql.Register

Bu fonksiyon `database/sql` paketinde bulunur ve üçüncü parti veritabanı sürücüleri kullandığınızda bu sürücüleri kaydetmeye yarar. Bu sürücülerin tamamı kendilerini kaydetmek için `init()` içinde `Register(name string, driver driver.Driver)` fonksiyonunu çağırmalıdır.

Buna karşılık gelen mymysql ve sqlite3 sürücü koduna bir göz atalım:
```Go
	//https://github.com/mattn/go-sqlite3 sürücüsü
	func init() {
	    sql.Register("sqlite3", &SQLiteDriver{})
	}

	//https://github.com/mikespook/mymysql sürücüsü
	// Sürücü database/sql içinde otomatik olarak kaydediliyor
	var d = Driver{proto: "tcp", raddr: "127.0.0.1:3306"}
	func init() {
	    Register("SET NAMES utf8")
	    sql.Register("mymysql", &d)
	}
```
Gördüğünüz gibi bütün üçüncü parti veritabanı sürücüleri kendilerini kaydetmek için bu fonksiyonu uyguluyor. Go ise kullanıcı sürücülerini `database/sql` içinde saklamak için bir map kullanıyor.
```Go
	var drivers = make(map[string]driver.Driver)

	drivers[name] = driver
```
Bu nedenle bu kayıt fonksiyonu, her biri farklı bir isme sahip olmak üzere ihtiyaç duyabileceğiniz kadar sürücü kaydedebilir.

Üçüncü parti sürücüler kullanırken hep şu kodu görürüz:
```Go
    import (
        "database/sql"
        _ "github.com/mattn/go-sqlite3"
    )
```
Buradaki alt çizgi (aynı zamanda 'blank' olarak da bilinir) `_`, yeni başlayanların çoğu için epey kafa karıştırıcı olabilir; fakat bu, Go'nun harika bir özelliğidir. Bu alt çizgi tanımlayıcısının fonksiyondan dönen değerleri atmak için kullanıldığını ve Go'da kodunuza import ettiğiniz tüm paketleri kullanmak zorunda olduğunuzu zaten biliyoruz. Dolayısıyla blank, import ile birlikte kullanıldığında, o paketi doğrudan kullanmadan sadece init() fonksiyonunu çalıştırmanız gerektiği anlamına gelir. Bu da veritabanı sürücülerini kaydetme senaryosuna kusursuz biçimde uyar.

## driver.Driver

`Driver`, bir `Conn` interface'i döndüren `Open(name string)` methodunu içeren bir interface'tir.
```Go
	type Driver interface {
	    Open(name string) (Conn, error)
	}
```
Bu tek kullanımlık bir Conn'dur; yani her goroutine'de yalnızca bir kez kullanılabilir. Aşağıdaki kod hataların oluşmasına yol açacaktır:
```Go
	...
	go goroutineA (Conn)  // sorgu
	go goroutineB (Conn)  // ekleme
	...
```
Go hangi goroutine'in hangi işlemi yaptığını bilmediği için, sorgu işlemi ekleme işleminin sonucunu alabilir ya da tam tersi olabilir.

Bütün üçüncü parti sürücüler, Conn'un adını ayrıştırıp doğru sonuçları döndürmek için bu fonksiyona sahip olmalıdır.

## driver.Conn

Bu, birkaç method içeren bir veritabanı bağlantısı interface'idir ve yukarıda da söylediğim gibi aynı Conn her goroutine'de yalnızca bir kez kullanılabilir.
```Go
	type Conn interface {
	    Prepare(query string) (Stmt, error)
	    Close() error
	    Begin() (Tx, error)
	}
```
- `Prepare`, sorgulama ve silme gibi işlemlere karşılık gelen SQL komutlarının hazırlık durumunu döndürür.
- `Close`, mevcut bağlantıyı kapatır ve kaynakları temizler. Üçüncü parti sürücülerin çoğu bir tür bağlantı havuzu uygular; bu yüzden beklenmedik hatalara yol açabilecek şekilde bağlantıları önbelleğe almanıza gerek yoktur.
- `Begin`, bir transaction (işlem) tutamacını temsil eden bir Tx döndürür. Bunu sorgulama, güncelleme, transaction'ları geri alma gibi işler için kullanabilirsiniz.

## driver.Stmt

Bu, Conn'a karşılık gelen bir hazır durumdur; bu yüzden (Conn'da olduğu gibi) her goroutine'de yalnızca bir kez kullanılabilir.
```Go
	type Stmt interface {
	    Close() error
	    NumInput() int
	    Exec(args []Value) (Result, error)
	    Query(args []Value) (Rows, error)
	}
```
- `Close`, mevcut bağlantıyı kapatır; fakat bir sorgu işlemi çalıştırıyorsa satır verisini yine de döndürür.
- `NumInput`, zorunlu argümanların sayısını döndürür. Sonuç 0'dan büyük olduğunda veritabanı sürücüleri kendilerini çağıranın argümanlarını denetlemelidir; veritabanı sürücüleri herhangi bir zorunlu argüman bilmiyorsa -1 döner.
- `Exec`, `Prepare` içinde hazırlanan `update/insert` SQL komutlarını çalıştırır ve `Result` döndürür.
- `Query`, `Prepare` içinde hazırlanan `select` SQL komutunu çalıştırır ve satır verisini döndürür.

## driver.Tx

Genel olarak transaction tutamaçlarında yalnızca gönderme veya geri alma methodları bulunur; veritabanı sürücülerinin de yalnızca bu iki methodu uygulaması yeterlidir.
```Go
	type Tx interface {
	    Commit() error
	    Rollback() error
	}
```
## driver.Execer

Bu, isteğe bağlı bir interface'tir.
```Go
	type Execer interface {
	    Exec(query string, args []Value) (Result, error)
	}
```
Sürücü bu interface'i uygulamıyorsa, DB.Exec'i çağırdığınızda otomatik olarak Prepare çağrılır ve ardından Stmt döndürülür. Bundan sonra Stmt'in Exec methodu çalıştırılır ve sonra Stmt kapatılır.

## driver.Result

Bu, `update/insert` işlemlerinin sonuçları için kullanılan interface'tir.
```Go
	type Result interface {
	    LastInsertId() (int64, error)
	    RowsAffected() (int64, error)
	}
```
- `LastInsertId`, bir veritabanı ekleme işleminden sonra otomatik artan Id numarasını döndürür.
- `RowsAffected`, sorgu işlemlerinden etkilenen satırları döndürür.

## driver.Rows

Bu, bir sorgu işleminin sonucu için kullanılan interface'tir.
```Go
	type Rows interface {
	    Columns() []string
	    Close() error
	    Next(dest []Value) error
	}
```
- `Columns`, veritabanı tablolarının alan bilgisini döndürür. Döndürülen slice yalnızca SQL sorgusundaki alanlarla birebir örtüşür; o veritabanı tablosunun bütün alanlarını döndürmez.
- `Close`, Rows yineleyicisini kapatır.
- `Next`, sonraki veriyi döndürüp dest'e atar, bütün string'leri byte dizilerine çevirir ve başka veri kalmadıysa io.EOF hatasını alır.

## driver.RowsAffected

Bu, int64 için bir takma addır; fakat Result interface'ini uygular.
```Go
	type RowsAffected int64

	func (RowsAffected) LastInsertId() (int64, error)

	func (v RowsAffected) RowsAffected() (int64, error)
```
## driver.Value

Bu, her türden veriyi içerebilen boş bir interface'tir.
```Go
	type Value interface{}
```
Value, sürücülerin üzerinde işlem yapabileceği bir şey ya da nil olmalıdır; dolayısıyla aşağıdaki türlerden biri olması gerekir:
```Go
	int64
	float64
	bool
	[]byte
	string   [*] string döndüremeyen Rows.Next hariç
	time.Time
```
## driver.ValueConverter

Bu, normal değerleri driver.Value'ya çevirmek için bir interface tanımlar.
```Go
	type ValueConverter interface {
	    ConvertValue(v interface{}) (Value, error)
	}
```
Bu interface veritabanı sürücülerinde sıkça kullanılır ve pek çok faydalı özelliği vardır:

- driver.Value'yu karşılık gelen veritabanı alan türüne çevirir; örneğin int64'ü uint16'ya çevirir.
- Veritabanı sorgu sonuçlarını driver.Value'ya çevirir.
- `scan` fonksiyonunda driver.Value'yu kullanıcı tanımlı bir değere çevirir.

## driver.Valuer

Bu, driver.Value döndürmek için bir interface tanımlar.
```Go
	type Valuer interface {
	    Value() (Value, error)
	}
```
Pek çok tür, kendisi ile driver.Value arasında dönüşüm yapmak için bu interface'i uygular.

Bu noktada Go'da veritabanı sürücüsü geliştirmek hakkında biraz bilgi sahibi olmuş olmalısınız. Ekleme, silme, güncelleme gibi işlemler için interface'leri uygulayabildiğinizde, geriye yalnızca belirli veritabanlarıyla iletişim kurmakla ilgili birkaç sorun kalır.

## database/sql

database/sql, veritabanı işlemlerini daha kolay hale getirmek için database/sql/driver üzerine daha da üst seviye methodlar tanımlar ve bir bağlantı havuzu uygulamanızı önerir.
```Go
	type DB struct {
	    driver   driver.Driver
	    dsn      string
	    mu       sync.Mutex // freeConn ve closed'ı korur
	    freeConn []driver.Conn
	    closed   bool
	}
```
Gördüğünüz gibi `Open` fonksiyonu, içinde bir freeConn bulunan bir DB döndürüyor; işte bu basit bir bağlantı havuzudur. Uygulanışı oldukça basit ve çirkindir. Bir bağlantıyı bağlantı havuzuna koymak için Db.prepare fonksiyonunda `defer db.putConn(ci, err)` kullanır. Conn fonksiyonunu her çağırdığınızda freeConn'un uzunluğunu denetler. Uzunluk 0'dan büyükse yeniden kullanılabilir bir bağlantı var demektir ve bu bağlantı size doğrudan döndürülür. Aksi hâlde yeni bir bağlantı oluşturup döndürür.

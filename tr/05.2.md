# 5.2 MySQL

LAMP yığını son yıllarda internette çok popüler oldu ve LAMP'taki M harfi MySQL'i temsil ediyor. MySQL, açık kaynaklı ve kullanımı kolay olduğu için ünlüdür. Bu nedenle pek çok web sitesinin arka ucunda fiilî standart veritabanı hâline gelmiştir.

## MySQL sürücüleri

Go'da MySQL'i destekleyen birkaç sürücü var. Bunların bir kısmı `database/sql` interface'ini (arayüzünü) uygular, diğerleri ise kendi interface standartlarını kullanır.

- [https://github.com/go-sql-driver/mysql](https://github.com/go-sql-driver/mysql) `database/sql`'i destekler, saf Go ile yazılmıştır.
- [https://github.com/ziutek/mymysql](https://github.com/ziutek/mymysql) `database/sql`'i ve kullanıcı tanımlı interface'leri destekler, saf Go ile yazılmıştır.

Aşağıdaki örneklerde ilk sürücüyü kullanacağım (kendi kişisel projelerimde de bunu kullanıyorum) ve şu nedenlerle onu kullanmanızı tavsiye ediyorum:

- Yeni bir veritabanı sürücüsüdür ve daha fazla özelliği destekler.
- `database/sql` interface standartlarını tam olarak destekler.
- Thread güvenli, keep-alive ve uzun bağlantıları destekler.

## Örnekler

İlerleyen bölümlerde farklı veritabanları için aynı veritabanı tablo yapısını kullanacağım; SQL'i şu şekilde oluşturalım:
```sql
	CREATE TABLE `userinfo` (
	    `uid` INT(10) NOT NULL AUTO_INCREMENT,
	    `username` VARCHAR(64) NULL DEFAULT NULL,
	    `department` VARCHAR(64) NULL DEFAULT NULL,
	    `created` DATE NULL DEFAULT NULL,
	    PRIMARY KEY (`uid`)
	);
```	
Aşağıdaki örnek, `database/sql` interface standartlarına dayanarak bir veritabanı üzerinde nasıl işlem yapılacağını gösteriyor.
```Go
	package main
	
	import (
	    _ "github.com/go-sql-driver/mysql"
	    "database/sql"
	    "fmt"
	)
	
	func main() {
	    db, err := sql.Open("mysql", "astaxie:astaxie@/test?charset=utf8")
	    checkErr(err)
	
	    // ekleme
	    stmt, err := db.Prepare("INSERT userinfo SET username=?,department=?,created=?")
	    checkErr(err)
	
	    res, err := stmt.Exec("astaxie", "研发部门", "2012-12-09")
	    checkErr(err)
	
	    id, err := res.LastInsertId()
	    checkErr(err)
	
	    fmt.Println(id)
	    // güncelleme
	    stmt, err = db.Prepare("update userinfo set username=? where uid=?")
	    checkErr(err)
	
	    res, err = stmt.Exec("astaxieupdate", id)
	    checkErr(err)
	
	    affect, err := res.RowsAffected()
	    checkErr(err)
	
	    fmt.Println(affect)
	
	    // sorgulama
	    rows, err := db.Query("SELECT * FROM userinfo")
	    checkErr(err)
	
	    for rows.Next() {
	        var uid int
	        var username string
	        var department string
	        var created string
	        err = rows.Scan(&uid, &username, &department, &created)
	        checkErr(err)
	        fmt.Println(uid)
	        fmt.Println(username)
	        fmt.Println(department)
	        fmt.Println(created)
	    }
	    
	    rows.Close()
	
	    // silme
	    stmt, err = db.Prepare("delete from userinfo where uid=?")
	    checkErr(err)
	
	    res, err = stmt.Exec(id)
	    checkErr(err)
	
	    affect, err = res.RowsAffected()
	    checkErr(err)
	
	    fmt.Println(affect)
	
	    db.Close()
	
	}
	
	func checkErr(err error) {
	    if err != nil {
	        panic(err)
	    }
	}
```
Buradaki önemli fonksiyonlardan birkaçını açıklayayım:

- `sql.Open()` kayıtlı bir veritabanı sürücüsünü açar. Go-MySQL-Driver, mysql sürücüsünü burada kaydetmiştir. İkinci argüman, veritabanı bağlantısına ilişkin bilgileri tanımlayan DSN'dir (Data Source Name). Şu biçimleri destekler:

		user@unix(/path/to/socket)/dbname?charset=utf8
		user:password@tcp(localhost:5555)/dbname?charset=utf8
		user:password@/dbname
		user:password@tcp([de:ad:be:ef::ca:fe]:80)/dbname

- `db.Prepare()` çalıştırılacak olan bir SQL işlemi döndürür. Aynı zamanda SQL çalıştırıldıktan sonra çalıştırma durumunu da döndürür.
- `db.Query()` SQL'i çalıştırır ve bir Rows sonucu döndürür.
- `stmt.Exec()` hazırlanıp Stmt içinde saklanmış olan SQL'i çalıştırır.

Argümanları geçirmek için `=?` biçimini kullandığımıza dikkat edin. Bu, SQL enjeksiyon saldırılarını önlemek için gereklidir.

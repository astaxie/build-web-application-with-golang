# 5.5 Beedb ile ORM tabanlı geliştirme

( ***beedb projesinin bakımı artık yapılmıyor, fakat kod hâlâ yerinde duruyor*** )

beedb, benim Go ile geliştirdiğim bir ORM'dir ( nesne-ilişkisel eşleyici ).
Veritabanları üzerinde işlem yapmak için idiomatik Go kullanır; struct'tan veritabanına eşlemeyi gerçekleştirir ve hafif bir Go ORM çatısı gibi davranır. Bu ORM'i geliştirmedeki amacım sadece insanların bir ORM'in nasıl yazıldığını öğrenmesine yardım etmek değil, aynı zamanda veri kalıcılığı söz konusu olduğunda işlevsellik ile performans arasında iyi bir denge bulmaktır.

beedb, temel ORM işlevselliğini destekleyen açık kaynaklı bir projedir, fakat ilişkisel sorguları desteklemez.

beedb, `database/sql` arayüz standartlarını desteklediği için bu arayüzü uygulayan her sürücü beedb ile kullanılabilir. Ben aşağıdaki sürücüleri test ettim:

Mysql: [github/go-mysql-driver/mysql](https://github.com/go-sql-driver/mysql)

PostgreSQL: [github.com/lib/pq](https://github.com/lib/pq)

SQLite: [github.com/mattn/go-sqlite3](https://github.com/mattn/go-sqlite3)

Mysql: [github.com/ziutek/mymysql/godrv](https://github.com/ziutek/mymysql)

MS ADODB: [github.com/mattn/go-adodb](https://github.com/mattn/go-adodb)

Oracle: [github.com/mattn/go-oci8](https://github.com/mattn/go-oci8)

ODBC: [bitbucket.org/miquella/mgodbc](https://bitbucket.org/miquella/mgodbc)

## Kurulum

beedb'yi yerel makinenize kurmak için `go get` kullanabilirsiniz.

	go get github.com/astaxie/beedb

## İlklendirme

Öncelikle gerekli tüm paketleri import etmeniz gerekiyor:
```Go
	import (
	    "database/sql"
	    "github.com/astaxie/beedb"
	    _ "github.com/ziutek/mymysql/godrv"
	)
```
Ardından bir veritabanı bağlantısı açıp bir beedb nesnesi oluşturmalısınız (bu örnekte MySQL):
```Go
	db, err := sql.Open("mymysql", "test/xiemengjun/123456")
	if err != nil {
	    panic(err)
	}
	orm := beedb.New(db)
```
`beedb.New()` aslında iki argüman alır. Birincisi veritabanı nesnesidir, ikincisi ise hangi veritabanı motorunu kullandığınızı belirtir. MySQL/SQLite kullanıyorsanız ikinci argümanı atlayabilirsiniz.

Aksi hâlde bu argümanın verilmesi gerekir. Örneğin SQLServer için:
```Go
	orm = beedb.New(db, "mssql")
```
PostgreSQL:
```Go
	orm = beedb.New(db, "pg")
```
beedb hata ayıklamayı destekler. Etkinleştirmek için aşağıdaki kodu kullanın:
```Go
	beedb.OnDebug=true
```
Sırada, önceki bölümlerde kullandığımız `Userinfo` veritabanı tablosu için bir struct var.
```Go
	type Userinfo struct {
	    Uid     int `PK` // birincil anahtar id değilse, kendi belirlediğiniz birincil anahtar için `PK` etiketini eklemeniz gerekir.
	    Username    string
	    Departname  string
	    Created     time.Time
	}
```
beedb'nin camelcase adları küçük harfli snake case biçimine otomatik çevirdiğine dikkat edin. Örneğin struct adımız `UserInfo` ise, beedb bunu veritabanında `user_info` hâline getirir. Aynı kural struct alan adları için de geçerlidir.


## Veri ekleme

Aşağıdaki örnek, ham SQL komutları kullanmak yerine bir struct'ı kaydetmek için beedb'yi nasıl kullanacağınızı gösteriyor. Değişikliği uygulamak için beedb'nin Save methodunu kullanıyoruz.
```Go
	var saveone Userinfo
	saveone.Username = "Test Add User"
	saveone.Departname = "Test Add Departname"
	saveone.Created = time.Now()
	orm.Save(&saveone)
```
Kayıt eklendikten sonra `saveone.Uid` değerini kontrol edebilirsiniz; bu değer kendiliğinden artan bir ID'dir ve Save methodu bunu sizin için halleder.

beedb veri eklemenin başka bir yolunu daha sunar; bu da Go'nun `map` tipi üzerindendir.
```Go
	add := make(map[string]interface{})
	add["username"] = "astaxie"
	add["departname"] = "cloud develop"
	add["created"] = "2012-12-02"
	orm.SetTable("userinfo").Insert(add)
```
Birden fazla veri ekleme:
```Go
	addslice := make([]map[string]interface{}, 10)
	add:=make(map[string]interface{})
	add2:=make(map[string]interface{})
	add["username"] = "astaxie"
	add["departname"] = "cloud develop"
	add["created"] = "2012-12-02"
	add2["username"] = "astaxie2"
	add2["departname"] = "cloud develop2"
	add2["created"] = "2012-12-02"
	addslice = append(addslice, add, add2)
	orm.SetTable("userinfo").InsertBatch(addslice)
```
Yukarıda gösterilen yöntem, daha önce jquery kullandıysanız aşina olacağınız zincirleme sorgulara benzer. Çağrılardan sonra özgün ORM nesnesini döndürür ve diğer işlere devam eder.

`SetTable` methodu, ORM'e verimizi `userinfo` tablosuna eklemek istediğimizi söyler.

## Veri güncelleme

Verinin nasıl güncellendiğini görmek için yukarıdaki örnekle devam edelim. Artık saveone'ın birincil anahtarına (Uid) sahip olduğumuz için beedb, yeni bir kayıt eklemek yerine güncelleme işlemi yürütür.
```Go
	saveone.Username = "Update Username"
	saveone.Departname = "Update Departname"
	saveone.Created = time.Now()
	orm.Save(&saveone)  // güncelleme
```
Öncekinde olduğu gibi, veriyi güncellemek için `map` de kullanabilirsiniz:
```Go
	t := make(map[string]interface{})
	t["username"] = "astaxie"
	orm.SetTable("userinfo").SetPK("uid").Where(2).Update(t)
```
Yukarıda kullanılan methodlardan bazılarını açıklayayım:

- `.SetPK()`, ORM'e `userinfo` tablosundaki kayıtların birincil anahtarının `uid` olduğunu söyler.
- `.Where()` koşulları belirler ve birden fazla argümanı destekler. İlk argüman bir tam sayıysa, bu `Where("<primary key>=?", <value>)` ifadesinin kısa yazımıdır.
- `.Update()` methodu bir `map` alır ve veritabanını günceller.

## Veri sorgulama

beedb'nin sorgu arayüzü oldukça esnektir. Birkaç örneğe bakalım:

Örnek 1, birincil anahtarla sorgulama:
```Go
	var user Userinfo
	// Where iki argüman alır, tam sayıları destekler
	orm.Where("uid=?", 27).Find(&user)
```
Örnek 2:
```Go
	var user2 Userinfo
	orm.Where(3).Find(&user2) // birincil anahtarı atlayan kısa yazım
```
Örnek 3, diğer sorgu koşulları:
```Go
	var user3 Userinfo
	// Where iki argüman kabul eder, char tipi desteklenir.
	orm.Where("name = ?", "john").Find(&user3)
```
Örnek 4, daha karmaşık koşullar:
```Go
	var user4 Userinfo
	// Where üç argüman kabul eder
	orm.Where("name = ? and age < ?", "john", 88).Find(&user4)
```
Birden fazla kayıt almaya dair örnekler:

Örnek 1, `id>3` olan kayıtlardan 20. konumdan başlayarak 10 tanesini alır:
```Go
	var allusers []Userinfo
	err := orm.Where("id > ?", "3").Limit(10,20).FindAll(&allusers)
```
Örnek 2, limit'in ikinci argümanını atlar; böylece 0'dan başlar ve 10 kayıt alır:
```Go
	var tenusers []Userinfo
	err := orm.Where("id > ?", "3").Limit(10).FindAll(&tenusers)
```
Örnek 3, tüm kayıtları alır:
```Go
	var everyone []Userinfo
	err := orm.OrderBy("uid desc,username asc").FindAll(&everyone)
```
Gördüğünüz gibi Limit methodu sonuç sayısını sınırlamak içindir.

- `.Limit()` iki argümanı destekler: sonuç sayısı ve başlangıç konumu. Başlangıç konumunun öntanımlı değeri 0'dır.
- `.OrderBy()` sonuçları sıralamak içindir. Argümanı sıralama koşuludur.

Buradaki tüm örnekler kayıtları basitçe struct'lara eşliyor. Veriyi aşağıdaki gibi doğrudan bir `map` içine de koyabilirsiniz:
```Go
	a, _ := orm.SetTable("userinfo").SetPK("uid").Where(2).Select("uid,username").FindMap()
```
- `.Select()`, veritabanı tablosundan kaç alan almak istediğinizi beedb'ye söyler. Belirtilmezse öntanımlı olarak tüm alanlar döner.
- `.FindMap()`, `[]map[string][]byte` tipini döndürür; bu yüzden diğer tiplere dönüştürme işini kendiniz yapmanız gerekir.

## Veri silme

beedb, veri silmek için zengin methodlar sunar.

Örnek 1, tek bir kaydı silme:
```Go
	// saveone yukarıdaki örnektekiyle aynıdır.
	orm.Delete(&saveone)
```
Örnek 2, birden fazla kaydı silme:
```Go
	// alluser birden fazla kaydı alan slice'tır.
	orm.DeleteAll(&alluser)
```
Örnek 3, SQL ile kayıt silme:
```Go
	orm.SetTable("userinfo").Where("uid>?", 3).DeleteRow()
```
## İlişkisel sorgular

beedb, struct'lar arasında join yapmayı desteklemez.
Fakat bazı uygulamaların bu özelliğe ihtiyacı olduğundan, işte bunu gerçekleştirmenin bir yolu:
```Go
	a, _ := orm.SetTable("userinfo").Join("LEFT", "userdetail", "userinfo.uid=userdetail.uid")
		.Where("userinfo.uid=?", 1).Select("userinfo.uid,userinfo.username,userdetail.profile").FindMap()
```
Üç argüman alan `.Join()` adlı yeni bir method görüyoruz:

- Birinci argüman: Join tipi; INNER, LEFT, OUTER, CROSS vb.
- İkinci argüman: birleştirmek istediğiniz tablo.
- Üçüncü argüman: join koşulu.

## Group By ve Having

beedb, `group by` ve `having` için de bir gerçekleştirim sunar.
```Go
	a, _ := orm.SetTable("userinfo").GroupBy("username").Having("username='astaxie'").FindMap()
```
- `.GroupBy()`, group by için kullanılacak alanı belirtir.
- `.Having()`, having koşullarını belirtir.

## Gelecek

beedb hakkında dünyanın dört bir yanından pek çok kişiden bolca geri bildirim aldım ve şu noktaları yeniden düzenlemeyi düşünüyorum:

- CRUD işlemlerini kolaylaştırmak için `database/sql/driver`'a benzer bir interface tasarımı uygulamak.
- Bire bir, bire çok ve çoka çok gibi ilişkisel veritabanı bağıntılarını gerçekleştirmek. İşte bir örnek:
```Go
				type Profile struct {
					Nickname string
					Mobile   string
				}
				
				type Userinfo struct {
					Uid         int
					PK_Username string
					Departname  string
					Created     time.Time
					Profile     HasOne
				}
```		 
- Tabloları ve indeksleri otomatik oluşturmak.
- goroutine'ler kullanarak bir bağlantı havuzu gerçekleştirmek.

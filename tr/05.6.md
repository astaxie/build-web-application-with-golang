# 5.6 NoSQL veritabanı

NoSQL veritabanları, yatay ölçeklenme ve daha yüksek erişilebilirlik elde etmek için tipik ilişkisel veritabanlarına göre daha gevşek tutarlılık modelleri kullanan bir veri saklama ve veri getirme mekanizması sunar. Bazı yazarlar, kimi NoSQL sistemlerinin SQL benzeri sorgu dillerinin kullanılmasına izin verdiğini vurgulamak için bunlara "Not only SQL" (yalnızca SQL değil) adını verir.

Go, 21. yüzyılın C dili olarak NoSQL veritabanlarını iyi destekler; popüler redis, mongoDB, Cassandra ve Membase NoSQL veritabanları da bunlara dahildir.

## redis

redis, tıpkı Memcached gibi bir anahtar-değer saklama sistemidir ve string, list, set, zset(sıralı küme) ve hash değer tiplerini destekler.

redis için birkaç Go veritabanı sürücüsü mevcut:
- [https://github.com/gomodule/redigo](https://github.com/gomodule/redigo)
- [https://github.com/go-redis/redis](https://github.com/go-redis/redis)
- [https://github.com/hoisie/redis](https://github.com/hoisie/redis)
- [https://github.com/alphazero/Go-Redis](https://github.com/alphazero/Go-Redis)
- [https://github.com/simonz05/godis](https://github.com/simonz05/godis)

Şimdi redigo sürücüsünü kullanarak bir veritabanı üzerinde nasıl işlem yapıldığına bakalım:
```Go

	package main

	import (
		"fmt"
		"github.com/gomodule/redigo/redis"
		"os"
    	"os/signal"
		"syscall"
		"time"
	)

	var (
		Pool *redis.Pool
	)

	func init() {
		redisHost := ":6379"
		Pool = newPool(redisHost)
		close()
	}

	func newPool(server string) *redis.Pool {

		return &redis.Pool{

			MaxIdle:     3,
			IdleTimeout: 240 * time.Second,

			Dial: func() (redis.Conn, error) {
				c, err := redis.Dial("tcp", server)
				if err != nil {
					return nil, err
				}
				return c, err
			},

			TestOnBorrow: func(c redis.Conn, t time.Time) error {
				_, err := c.Do("PING")
				return err
			},
		}
	}

	func close() {
		c := make(chan os.Signal, 1)
		signal.Notify(c, os.Interrupt)
		signal.Notify(c, syscall.SIGTERM)
		signal.Notify(c, syscall.SIGKILL)
		go func() {
			<-c
			Pool.Close()
			os.Exit(0)
		}()
	}

	func Get(key string) ([]byte, error) {

		conn := Pool.Get()
		defer conn.Close()

		var data []byte
		data, err := redis.Bytes(conn.Do("GET", key))
		if err != nil {
			return data, fmt.Errorf("%s anahtarı alınırken hata: %v", key, err)
		}
		return data, err
	}

	func main() {
		test, err := Get("test")
		fmt.Println(test, err)
	}

```

Bu paketlerin sonuncusunu forklayıp bazı hataları düzelttim ve kısa URL servisimde kullandım (günde 2 milyon sayfa görüntüleme).

- [https://github.com/astaxie/goredis](https://github.com/astaxie/goredis)

Şimdi forkladığım sürücüyü kullanarak bir veritabanı üzerinde nasıl işlem yapıldığına bakalım:
```Go
	package main

	import (
		"github.com/astaxie/goredis"
		"fmt"
	)

	func main() {
		var client goredis.Client
		
		// Redis'in öntanımlı portunu ayarla
		client.Addr = "127.0.0.1:6379"
		
		// string işlemleri
		client.Set("a", []byte("hello"))
		val, _ := client.Get("a")
		fmt.Println(string(val))
		client.Del("a")

		// list işlemleri
		vals := []string{"a", "b", "c", "d", "e"}
		for _, v := range vals {
			client.Rpush("l", []byte(v))
		}
		dbvals,_ := client.Lrange("l", 0, 4)
		for i, v := range dbvals {
			println(i,":",string(v))
		}
		client.Del("l")
	}
```
Görüyoruz ki Go'da redis ile çalışmak oldukça kolay ve performansı da yüksek. İstemci komutları neredeyse redis'in yerleşik komutlarıyla aynı.

## mongoDB

mongoDB (adı "humongous" kelimesinden gelir), 10gen tarafından geliştirilen ve desteklenen açık kaynaklı, belge yönelimli bir veritabanı sistemidir. NoSQL veritabanı sistemleri ailesinin bir üyesidir. "Klasik" bir ilişkisel veritabanında olduğu gibi veriyi tablolarda saklamak yerine, MongoDB yapılandırılmış veriyi dinamik şemalara sahip JSON benzeri belgeler olarak saklar (MongoDB bu biçime BSON adını verir); böylece belirli uygulama türlerinde veri entegrasyonu daha kolay ve daha hızlı hale gelir.

![](images/5.6.mongodb.png?raw=true)

Şekil 5.1 MongoDB ile Mysql karşılaştırması

mongoDB için en iyi sürücünün adı `mgo`; gelecekte standart kütüphaneye dahil edilmesi de mümkün.

mgo'yu kurmak için:

```Go
	go get gopkg.in/mgo.v2
```

İşte örnek:
```Go

	package main

	import (
		"fmt"
		"gopkg.in/mgo.v2"
		"gopkg.in/mgo.v2/bson"
		"log"
	)

	type Person struct {
		Name  string
		Phone string
	}

	func main() {
		session, err := mgo.Dial("server1.example.com,server2.example.com")
		if err != nil {
			panic(err)
		}
		defer session.Close()

		// İsteğe bağlı. Oturumu monotonik davranışa geçir.
		session.SetMode(mgo.Monotonic, true)

		c := session.DB("test").C("people")
		err = c.Insert(&Person{"Ale", "+55 53 8116 9639"},
			&Person{"Cla", "+55 53 8402 8510"})
		if err != nil {
			log.Fatal(err)
		}

		result := Person{}
		err = c.Find(bson.M{"name": "Ale"}).One(&result)
		if err != nil {
			log.Fatal(err)
		}

		fmt.Println("Telefon:", result.Phone)
	}

```

Gördüğünüz gibi veritabanı işlemlerini mgo ile yapmakla beedb ile yapmak arasında büyük bir fark yok; ikisi de struct'lara dayanıyor. İşleri Go usulü yapmak budur.

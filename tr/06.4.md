# 6.4 Oturum çalınmasını engelleme

Oturum çalınması, yaygın ama bir o kadar da ciddi bir güvenlik tehdididir. İstemciler, sunucularla haberleşirken doğrulama ve başka amaçlar için oturum id'lerini kullanır. Ne yazık ki kötü niyetli üçüncü partiler bazen bu haberleşmeyi izleyip istemcinin oturum id'sini çözebilir. 

Bu bölümde, eğitim amacıyla bir oturumun nasıl çalınacağını size göstereceğiz.

## Oturum çalma süreci

Aşağıdaki kod, `count` değişkeni için bir sayaçtır:
```Go
	func count(w http.ResponseWriter, r *http.Request) {
	    sess := globalSessions.SessionStart(w, r)
	    ct := sess.Get("countnum")
	    if ct == nil {
	        sess.Set("countnum", 1)
	    } else {
	        sess.Set("countnum", (ct.(int) + 1))
	    }
	    t, _ := template.ParseFiles("count.gtpl")
	    w.Header().Set("Content-Type", "text/html")
	    t.Execute(w, sess.Get("countnum"))
	}
```
`count.gtpl` dosyasının içeriği şöyledir:

	Hi. Now count:{{.}}

HTTP durumsuz olduğu için, firefox'tan gelen oturum id'sinin taklit edildiğini anlamanın hiçbir yolu yoktur; chrome de kendi oturum id'sinin çalındığını bilemez.

## oturum çalınmasını engelleme

### sadece çerez ve token

Oturum çalmaya dair bu basit örnek sayesinde, bunun ne kadar tehlikeli olduğunu görebilirsiniz; çünkü saldırganların istedikleri her şeyi yapmasına imkân tanır. Peki oturum çalınmasını nasıl engelleyebiliriz?

İlk adım, oturum id'lerini URL yeniden yazma yoluyla değil, yalnızca çerezlerde tutmaktır. Ayrıca çerezin httponly özelliğini true olarak ayarlamalıyız. Bu, istemci tarafındaki betiklerin oturum id'sine erişmesini kısıtlar. Bu teknikleri kullandığınızda çerezlere XSS ile erişilemez ve oturum id'sini bir çerez yöneticisinden almak, az önce gösterdiğimiz kadar kolay olmaz.

İkinci adım, her isteğe bir token eklemektir. Önceki bölümlerde tekrarlanan form gönderimlerini ele alış biçimimize benzer şekilde, içinde bir token bulunan gizli bir alan ekleriz. Sunucuya bir istek gönderildiğinde, isteğin benzersiz olduğunu kanıtlamak için bu token'ı doğrulayabiliriz.
```Go	
	h := md5.New()
	salt:="astaxie%^7&8888"
	io.WriteString(h,salt+time.Now().String())
	token:=fmt.Sprintf("%x",h.Sum(nil))
	if r.Form["token"]!=token{
	    // giriş yapmasını iste
	}
	sess.Set("token",token)
```
### Oturum id'si zaman aşımı

Bir diğer çözüm, her oturuma bir oluşturulma zamanı eklemek ve süresi dolmuş oturum id'lerini yenileriyle değiştirmektir. Bu, çalma girişiminin çok geç yapılması gibi belirli durumlarda oturum çalınmasını engelleyebilir.
```Go
	createtime := sess.Get("createtime")
	if createtime == nil {
	    sess.Set("createtime", time.Now().Unix())
	} else if (createtime.(int64) + 60) < (time.Now().Unix()) {
	    globalSessions.SessionDestroy(w, r)
	    sess = globalSessions.SessionStart(w, r)
	}
```
Oluşturulma zamanını saklamak için bir değer belirliyoruz ve süresinin dolup dolmadığını kontrol ediyoruz (ben burada 60 saniye ayarladım). Bu adım, oturum çalma girişimlerini çoğu zaman boşa çıkarır.

Yukarıda anlatılan iki çözümü birleştirerek oturum çalma girişimlerinin çoğunun başarıya ulaşmasını engelleyebilirsiniz. Bir yandan, sık sık sıfırlanan oturum id'leri sayesinde saldırganın eline hep süresi dolmuş ve işe yaramaz oturum id'leri geçer; diğer yandan, çerezlerde httponly özelliğini ayarlayıp oturum id'lerinin yalnızca çerezlerle taşınmasını sağladığınızda URL tabanlı bütün saldırılar etkisiz hâle gelir. Son olarak çerezlerimizde `MaxAge=0` ayarını yaparız; bu da oturum id'lerinin tarayıcı geçmişine kaydedilmeyeceği anlamına gelir.

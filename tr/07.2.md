# 7.2 JSON

JSON (JavaScript Object Notation), metin tabanlı betimlemeye dayanan hafif bir veri değişim dilidir. Kendi kendini betimlemesi, kolay anlaşılması gibi avantajları vardır. JavaScript'in bir alt kümesi olmasına rağmen JSON farklı bir metin biçimi kullanır; bu nedenle bağımsız bir dil olarak kabul edilebilir. JSON, C ailesindeki dillere benzerlik gösterir.

JSON ile XML arasındaki en büyük fark, XML'in eksiksiz bir işaretleme dili olması, JSON'un ise olmamasıdır. JSON, XML'den daha küçük ve daha hızlıdır; bu yüzden tarayıcılarda ayrıştırılması çok daha kolay ve hızlıdır. Birçok açık platformun veri değişim arayüz dili olarak JSON'u seçmesinin nedenlerinden biri de budur.

JSON, web geliştirmede gitgide daha önemli hâle geldiğine göre, Go'nun JSON'a ne düzeyde destek verdiğine bakalım. Go'nun standart kütüphanesinin JSON kodlama ve çözme konusunda çok iyi bir desteğe sahip olduğunu göreceksiniz.

Bir önceki bölümdeki örneği burada JSON ile gösteriyoruz:
```json
{"servers":[{"serverName":"Shanghai_VPN","serverIP":"127.0.0.1"},{"serverName":"Beijing_VPN","serverIP":"127.0.0.2"}]}
```	
Bu bölümün geri kalanında Go'daki JSON kavramlarını tanıtmak için bu JSON verisini kullanacağız.

## JSON ayrıştırma

### struct'a ayrıştırma

Yukarıdaki örnekteki JSON'un elimizde olduğunu varsayalım. Bu veriyi nasıl ayrıştırıp Go'daki bir struct'a eşleyebiliriz? Go, tam da bu amaç için aşağıdaki fonksiyonu sunuyor:
```Go
func Unmarshal(data []byte, v interface{}) error
```
Bu fonksiyonu şu şekilde kullanabiliriz:

```Go
package main

import (
    "encoding/json"
    "fmt"
)

type Server struct {
    ServerName string
    ServerIP   string
}

type Serverslice struct {
    Servers []Server
}

func main() {
    var s Serverslice
    str := `{"servers":[{"serverName":"Shanghai_VPN","serverIP":"127.0.0.1"},{"serverName":"Beijing_VPN","serverIP":"127.0.0.2"}]}`
    json.Unmarshal([]byte(str), &s)
    fmt.Println(s)
}
```
Yukarıdaki örnekte JSON'umuza karşılık gelen struct'ları Go'da tanımladık; JSON nesnelerinden oluşan dizi için slice, JSON anahtarlarımız için de alan adlarını kullandık. Peki Go, hangi JSON nesnesinin hangi struct alanına karşılık geldiğini nasıl biliyor? JSON'da `Foo` adında bir anahtarımız olduğunu varsayalım. Karşılık gelen alanı nasıl buluruz?

- Go önce, etiketi `Foo` içeren (baş harfi büyük) dışarı açık alanı bulmaya çalışır.
- Eşleşme bulunamazsa adı `Foo` olan alanı arar.
- Yine eşleşme yoksa, büyük-küçük harf duyarlılığını yok sayarak `FOO` ya da `FoO` gibi bir şey arar.

Atama yapılacak bütün alanların dışarı açık olması gerektiğini fark etmişsinizdir; Go yalnızca bulabildiği alanlara atama yapar, diğerlerini yok sayar. Büyük JSON veri yığınlarıyla uğraşmanız gerekiyor ama bunların yalnızca belirli bir alt kümesi işinize yarıyorsa bu çok kullanışlı olabilir; ihtiyacınız olmayan veriden kolayca kurtulabilirsiniz.

### interface'e ayrıştırma

Nasıl bir JSON bekleyeceğimizi önceden biliyorsak onu belirli bir struct'a ayrıştırabiliriz. Peki bilmiyorsak ne olacak?

Go'da bir interface{}'in her şey olabileceğini biliyoruz; dolayısıyla biçimini bilmediğimiz JSON'u saklamak için en iyi kap odur. JSON paketi, her türden JSON nesnesini ve dizisini saklamak için `map[string]interface{}` ve `[]interface{}` kullanır. JSON eşleme ilişkilerinin listesi şöyle:

- `bool`, `JSON booleans` değerlerini temsil eder,
- `float64`, `JSON numbers` değerlerini temsil eder,
- `string`, `JSON strings` değerlerini temsil eder,
- `nil`, `JSON null` değerini temsil eder.

Elimizde aşağıdaki JSON verisinin olduğunu varsayalım:
```Go
b := []byte(`{"Name":"Wednesday","Age":6,"Parents":["Gomez","Morticia"]}`)
```
Şimdi bu JSON'u bir interface{}'e ayrıştıralım:
```Go
var f interface{}
err := json.Unmarshal(b, &f)
```
`f`, anahtarları string, değerleri interface{} olan bir map saklar.
```Go
f = map[string]interface{}{
    "Name": "Wednesday",
    "Age":  6,
    "Parents": []interface{}{
        "Gomez",
        "Morticia",
    },
}
```
Peki bu veriye nasıl erişeceğiz? Type assertion (tür doğrulaması) ile.
```Go
m := f.(map[string]interface{})
```
Type assertion yapıldıktan sonra veriye erişmek için aşağıdaki kodu kullanabilirsiniz:
```Go
for k, v := range m {
    switch vv := v.(type) {
    case string:
        fmt.Println(k, "string'tir", vv)
    case int:
        fmt.Println(k, "int'tir", vv)
    case float64:
        fmt.Println(k,"float64'tür",vv)
    case []interface{}:
        fmt.Println(k, "bir dizidir:")
        for i, u := range vv {
            fmt.Println(i, u)
        }
    default:
        fmt.Println(k, "nasıl işleyeceğimi bilmediğim bir türde")
    }
}
```	
Gördüğünüz gibi, biçimini bilmediğimiz JSON'u artık interface{} ve type assertion aracılığıyla ayrıştırabiliyoruz.

Yukarıdaki örnek resmî çözümdür, fakat type assertion her zaman kullanışlı değildir. Bu yüzden bitly tarafından oluşturulup bakımı yapılan `simplejson` adlı açık kaynaklı bir projeyi öneriyorum. Biçimi bilinmeyen JSON'la başa çıkmak için bu projenin nasıl kullanılacağına dair bir örnek:
```Go
js, err := NewJson([]byte(`{
    "test": {
        "array": [1, "2", 3],
        "int": 10,
        "float": 5.150,
        "bignum": 9223372036854775807,
        "string": "simplejson",
        "bool": true
    }
}`))

arr, _ := js.Get("test").Get("array").Array()
i, _ := js.Get("test").Get("int").Int()
ms := js.Get("test").Get("string").MustString()
```	
Bunun ne kadar kullanışlı olduğunu görmek zor değil. Daha fazla bilgi için depoya göz atın: [https://github.com/bitly/go-simplejson](https://github.com/bitly/go-simplejson).

## JSON üretme

Birçok durumda JSON verisi üretip istemcilere yanıt vermemiz gerekir. Go'da JSON paketi, tam da bunu yapan `Marshal` adlı bir fonksiyona sahiptir:
```Go
func Marshal(v interface{}) ([]byte, error)
```
Bir sunucu bilgi listesi üretmemiz gerektiğini varsayalım. Elimizde şöyle bir örnek var:
```Go
package main

import (
    "encoding/json"
    "fmt"
)

type Server struct {
    ServerName string
    ServerIP   string
}

type Serverslice struct {
    Servers []Server
}

func main() {
    var s Serverslice
    s.Servers = append(s.Servers, Server{ServerName: "Shanghai_VPN", ServerIP: "127.0.0.1"})
    s.Servers = append(s.Servers, Server{ServerName: "Beijing_VPN", ServerIP: "127.0.0.2"})
    b, err := json.Marshal(s)
    if err != nil {
        fmt.Println("json hatası:", err)
    }
    fmt.Println(string(b))
}
```
Çıktı:
```json
{"Servers":[{"ServerName":"Shanghai_VPN","ServerIP":"127.0.0.1"},{"ServerName":"Beijing_VPN","ServerIP":"127.0.0.2"}]}
```	
Bildiğiniz gibi bütün alan adları büyük harfle başlıyor; fakat JSON anahtar adlarınızın küçük harfle başlamasını istiyorsanız `struct tag`'leri kullanmalısınız. Aksi hâlde Go, dahili alanlar için veri üretmez.
```Go
type Server struct {
    ServerName string `json:"serverName"`
    ServerIP   string `json:"serverIP"`
}

type Serverslice struct {
    Servers []Server `json:"servers"`
}
```	
Bu değişiklikten sonra öncekiyle aynı JSON verisini üretebiliriz.

JSON üretmeye çalışırken aklınızda tutmanız gereken birkaç nokta var:

- `"-"` içeren alan etiketleri çıktıya yazılmaz.
- Bir etiket özelleştirilmiş bir ad içeriyorsa Go, alan adı yerine bunu kullanır; yukarıdaki örnekteki `serverName` gibi.
- Bir etiket `omitempty` içeriyorsa, sıfır değerdeki bu alan çıktıya yazılmaz.
- Alan türü `bool`, string, int, `int64` vb. ise ve etiketi `",string"` içeriyorsa, Go bu alanı karşılık gelen JSON türüne dönüştürür.

Örnek:
```Go
type Server struct {
    // ID çıktıya yazılmayacak.
    ID int `json:"-"`

    // ServerName2 JSON türüne dönüştürülecek.
    ServerName  string `json:"serverName"`
    ServerName2 string `json:"serverName2,string"`

    // ServerIP boşsa çıktıya yazılmayacak.
    ServerIP   string `json:"serverIP,omitempty"`
}

s := Server {
    ID:         3,
    ServerName:  `Go "1.0" `,
    ServerName2: `Go "1.0" `,
    ServerIP:   ``,
}
b, _ := json.Marshal(s)
os.Stdout.Write(b)
```	
Çıktı:
```json
{"serverName":"Go \"1.0\" ","serverName2":"\"Go \\\"1.0\\\" \""}
```
`Marshal` fonksiyonu yalnızca başarılı olduğunda veri döndürür, bu yüzden aklımızda tutmamız gereken birkaç nokta var:

- JSON, anahtar olarak yalnızca string'leri destekler; bu yüzden bir map'i kodlamak istiyorsanız türünün `map[string]T` olması gerekir (`T`, Go'daki türdür).
- channel, kompleks türler ve fonksiyonlar gibi türler JSON'a kodlanamaz.
- Döngüsel veriyi kodlamaya çalışmayın, bu sonsuz özyinelemeye yol açar.
- Alan bir pointer (işaretçi) ise Go, onun işaret ettiği veriyi çıktıya yazar; nil'e işaret ediyorsa null yazar.

Bu bölümde Go'da JSON verisinin nasıl çözüleceğini ve kodlanacağını tanıttık. Ayrıca biçimi bilinmeyen JSON'u ayrıştırmak için kullanışlı olan `simplejson` adlı üçüncü parti bir projeye de baktık. Bunların hepsi, Go ile web uygulamaları geliştirirken işinize yarayacak kavramlar.

# 7.3 Regexp
Düzenli ifadeler ("Regexp"), desen eşleştirme ve metin işleme için karmaşık ama güçlü bir araçtır. Saf metin eşleştirmesi kadar iyi performans göstermese de daha esnektir. Söz dizimi sayesinde kaynak içeriğinizden hemen hemen her türlü metni filtreleyebilirsiniz. Web geliştirmede veri toplamanız gerekiyorsa, anlamlı verileri çekmek için Regexp kullanmak zor değildir.

Go'da regexp için resmî destek sağlayan `regexp` paketi bulunur. Başka programlama dillerinde regexp kullandıysanız bu paket size tanıdık gelecektir. Go'nun, `\C` dışında RE2 standardını uyguladığını unutmayın. Daha fazla ayrıntı için şu bağlantıyı izleyin: [http://code.google.com/p/re2/wiki/Syntax](http://code.google.com/p/re2/wiki/Syntax).

Go'nun `strings` paketi aslında arama (Contains, Index), değiştirme (Replace), ayrıştırma (Split, Join) gibi birçok işi yapabilir ve Regexp'ten daha hızlıdır. Ancak bunların hepsi basit işlemlerdir. Büyük/küçük harfe duyarsız bir string aramak isterseniz en iyi seçeneğiniz Regexp olmalıdır. Yani `strings` paketi ihtiyaçlarınız için yeterliyse onu kullanın; hem kullanımı hem okunması kolaydır. Daha gelişmiş işlemler yapmanız gerekiyorsa Regexp'i kullanın.

Önceki bölümlerdeki form doğrulamasını hatırlarsanız, kullanıcı girdisinin geçerliliğini denetlemek için Regexp kullanmıştık. Bütün karakterlerin UTF-8 olduğunu unutmayın. Şimdi Go'nun `regexp` paketini daha yakından öğrenelim!

## Eşleştirme

`regexp` paketinde eşleştirme yapan 3 fonksiyon vardır: bir desenle eşleşiyorsa `true`, aksi hâlde `false` döner.
```Go
func Match(pattern string, b []byte) (matched bool, error error)
func MatchReader(pattern string, r io.RuneReader) (matched bool, error error)
func MatchString(pattern string, s string) (matched bool, error error)
```
Üç fonksiyon da `pattern`'ın girdi kaynağıyla eşleşip eşleşmediğini denetler ve eşleşirse `true` döner. Ancak Regex'inizde söz dizimi hatası varsa bir hata döndürülür. Bu fonksiyonların üç girdi kaynağı şunlardır: `slice of byte`, `RuneReader` ve `string`.

Bir IP adresinin nasıl doğrulanacağına dair bir örnek:
```Go
func IsIP(ip string) (b bool) {
	if m, _ := regexp.MatchString("^[0-9]{1,3}\\.[0-9]{1,3}\\.[0-9]{1,3}\\.[0-9]{1,3}$", ip); !m {
		return false
	}
	return true
}
```
Gördüğünüz gibi `regexp` paketinde desen kullanmak pek farklı değil. Kullanıcı girdisinin geçerli olup olmadığını denetleyen bir örnek daha:
```Go
func main() {
	if len(os.Args) == 1 {
		fmt.Println("Kullanım: regexp [string]")
		os.Exit(1)
	} else if m, _ := regexp.MatchString("^[0-9]+$", os.Args[1]); m {
		fmt.Println("Sayı")
	} else {
		fmt.Println("Sayı değil")
	}
}
```
Yukarıdaki örneklerde içeriğin geçerli olup olmadığını denetlemek için `Match(Reader|String)` kullandık; hepsinin kullanımı kolay.

## Filtreleme

Eşleştirme modu içeriği doğrulayabilir ama içerikteki veriyi kesemez, filtreleyemez veya toplayamaz. Bunu yapmak istiyorsanız Regexp'in karmaşık modunu kullanmalısınız.

Diyelim ki bir crawler (veri toplayıcı) yazmamız gerekiyor. Veriyi filtrelemek ve kesmek için Regexp kullanmak zorunda olduğunuz duruma bir örnek:
```Go
package main

import (
	"fmt"
	"io/ioutil"
	"net/http"
	"regexp"
	"strings"
)

func main() {
	resp, err := http.Get("http://www.baidu.com")
	if err != nil {
		fmt.Println("http get hatası.")
	}
	defer resp.Body.Close()
	body, err := ioutil.ReadAll(resp.Body)
	if err != nil {
		fmt.Println("http okuma hatası")
		return
	}

	src := string(body)

	// HTML etiketlerini küçük harfe çevir.
	re, _ := regexp.Compile("\\<[\\S\\s]+?\\>")
	src = re.ReplaceAllStringFunc(src, strings.ToLower)

	// STYLE'ı kaldır.
	re, _ = regexp.Compile("\\<style[\\S\\s]+?\\</style\\>")
	src = re.ReplaceAllString(src, "")

	// SCRIPT'i kaldır.
	re, _ = regexp.Compile("\\<script[\\S\\s]+?\\</script\\>")
	src = re.ReplaceAllString(src, "")

	// Açılı parantez içindeki tüm HTML kodunu kaldır ve yerine satır sonu koy.
	re, _ = regexp.Compile("\\<[\\S\\s]+?\\>")
	src = re.ReplaceAllString(src, "\n")

	// Ardışık satır sonlarını kaldır.
	re, _ = regexp.Compile("\\s{2,}")
	src = re.ReplaceAllString(src, "\n")

	fmt.Println(strings.TrimSpace(src))
}
```
Bu örnekte karmaşık modun ilk adımı olarak Compile'ı kullanıyoruz. Compile, Regex söz diziminizin doğru olduğunu denetler, ardından diğer işlemlerde içeriği ayrıştırmak üzere bir `Regexp` döndürür.

Regexp söz diziminizi ayrıştıran bazı fonksiyonlar şunlardır:
```Go
func Compile(expr string) (*Regexp, error)
func CompilePOSIX(expr string) (*Regexp, error)
func MustCompile(str string) *Regexp
func MustCompilePOSIX(str string) *Regexp
```
`ComplePOSIX` ile `Compile` arasındaki fark şudur: ilki, en soldaki en uzun eşleşmeyi arayan POSIX söz dizimini kullanmak zorundadır; ikincisi ise yalnızca en soldaki eşleşmeyi arar. Örneğin `[a-z]{2,4}` Regexp'i ve `"aa09aaa88aaaa"` içeriği için `CompilePOSIX` `aaaa`, `Compile` ise `aa` döndürür. `Must` öneki, Regexp söz dizimi doğru olmadığında panic oluşacağı, aksi hâlde hata döneceği anlamına gelir.

Artık yeni bir Regexp'in nasıl oluşturulacağını bildiğimize göre, bu struct'ın sağladığı methodların içerik üzerinde işlem yapmamıza nasıl yardımcı olduğuna bakalım:
```Go
func (re *Regexp) Find(b []byte) []byte
func (re *Regexp) FindAll(b []byte, n int) [][]byte
func (re *Regexp) FindAllIndex(b []byte, n int) [][]int
func (re *Regexp) FindAllString(s string, n int) []string
func (re *Regexp) FindAllStringIndex(s string, n int) [][]int
func (re *Regexp) FindAllStringSubmatch(s string, n int) [][]string
func (re *Regexp) FindAllStringSubmatchIndex(s string, n int) [][]int
func (re *Regexp) FindAllSubmatch(b []byte, n int) [][][]byte
func (re *Regexp) FindAllSubmatchIndex(b []byte, n int) [][]int
func (re *Regexp) FindIndex(b []byte) (loc []int)
func (re *Regexp) FindReaderIndex(r io.RuneReader) (loc []int)
func (re *Regexp) FindReaderSubmatchIndex(r io.RuneReader) []int
func (re *Regexp) FindString(s string) string
func (re *Regexp) FindStringIndex(s string) (loc []int)
func (re *Regexp) FindStringSubmatch(s string) []string
func (re *Regexp) FindStringSubmatchIndex(s string) []int
func (re *Regexp) FindSubmatch(b []byte) [][]byte
func (re *Regexp) FindSubmatchIndex(b []byte) []int
```
Bu 18 method, aynı işlevlerin farklı girdi kaynakları (byte slice, string ve io.RuneReader) için tekrarlanmış hâllerinden oluşur; bu yüzden girdi kaynaklarını göz ardı ederek listeyi şöyle sadeleştirebiliriz:
```Go
func (re *Regexp) Find(b []byte) []byte
func (re *Regexp) FindAll(b []byte, n int) [][]byte
func (re *Regexp) FindAllIndex(b []byte, n int) [][]int
func (re *Regexp) FindAllSubmatch(b []byte, n int) [][][]byte
func (re *Regexp) FindAllSubmatchIndex(b []byte, n int) [][]int
func (re *Regexp) FindIndex(b []byte) (loc []int)
func (re *Regexp) FindSubmatch(b []byte) [][]byte
func (re *Regexp) FindSubmatchIndex(b []byte) []int
```
Kod örneği:
```Go
package main

import (
	"fmt"
	"regexp"
)

func main() {
	a := "I am learning Go language"

	re, _ := regexp.Compile("[a-z]{2,4}")

	// İlk eşleşmeyi bul.
	one := re.Find([]byte(a))
	fmt.Println("Find:", string(one))

	// Tüm eşleşmeleri bul ve bir slice'a kaydet; n 0'dan küçükse tüm eşleşmeler döner, 0'dan büyükse slice'ın uzunluğunu belirtir.
	all := re.FindAll([]byte(a), -1)
	fmt.Println("FindAll", all)

	// İlk eşleşmenin indeksini, yani başlangıç ve bitiş konumunu bul.
	index := re.FindIndex([]byte(a))
	fmt.Println("FindIndex", index)

	// Tüm eşleşmelerin indeksini bul, n yukarıdakiyle aynı işi yapar.
	allindex := re.FindAllIndex([]byte(a), -1)
	fmt.Println("FindAllIndex", allindex)

	re2, _ := regexp.Compile("am(.*)lang(.*)")

	// İlk alt eşleşmeyi bul ve dizi döndür; ilk eleman tüm elemanları, ikinci eleman ilk () grubunun sonucunu, üçüncü eleman ikinci () grubunun sonucunu içerir.
	// Çıktı: 
	// ilk eleman: "am learning Go language"
	// ikinci eleman: " learning Go ", boşlukların da çıktıya geleceğine dikkat edin.
	// üçüncü eleman: "uage"
	submatch := re2.FindSubmatch([]byte(a))
	fmt.Println("FindSubmatch", submatch)
	for _, v := range submatch {
		fmt.Println(string(v))
	}

	// FindIndex() ile aynı.
	submatchindex := re2.FindSubmatchIndex([]byte(a))
	fmt.Println(submatchindex)

	// FindAllSubmatch, tüm alt eşleşmeleri bulur.
	submatchall := re2.FindAllSubmatch([]byte(a), -1)
	fmt.Println(submatchall)

	// FindAllSubmatchIndex, tüm alt eşleşmelerin indeksini bulur.
	submatchallindex := re2.FindAllSubmatchIndex([]byte(a), -1)
	fmt.Println(submatchallindex)
}
```
Daha önce belirttiğimiz gibi Regexp'in eşleştirme için 3 methodu daha vardır. Bunlar, dışarı açık fonksiyonlarla tamamen aynı işi yapar. Aslında o dışarı açık fonksiyonlar arka planda bu methodları çağırır:
```Go
func (re *Regexp) Match(b []byte) bool
func (re *Regexp) MatchReader(r io.RuneReader) bool
func (re *Regexp) MatchString(s string) bool
```
Şimdi de Regexp kullanarak string'lerin nasıl değiştirileceğine bakalım:
```Go
func (re *Regexp) ReplaceAll(src, repl []byte) []byte
func (re *Regexp) ReplaceAllFunc(src []byte, repl func([]byte) []byte) []byte
func (re *Regexp) ReplaceAllLiteral(src, repl []byte) []byte
func (re *Regexp) ReplaceAllLiteralString(src, repl string) string
func (re *Regexp) ReplaceAllString(src, repl string) string
func (re *Regexp) ReplaceAllStringFunc(src string, repl func(string) string) string
```
Bunlar crawler örneğinde kullanıldı, bu yüzden burada daha fazla açıklamayacağız.

Şimdi `Expand`'in tanımına bakalım:
```Go
func (re *Regexp) Expand(dst []byte, template []byte, src []byte, match []int) []byte
func (re *Regexp) ExpandString(dst []byte, template string, src string, match []int) []byte
```
Peki `Expand`'i nasıl kullanıyoruz?
```Go
func main() {
	src := []byte(`
		call hello alice
		hello bob
		call hello eve
	`)
	pat := regexp.MustCompile(`(?m)(call)\s+(?P<cmd>\w+)\s+(?P<arg>.+)\s*$`)
	res := []byte{}
	for _, s := range pat.FindAllSubmatchIndex(src, -1) {
		res = pat.Expand(res, []byte("$cmd('$arg')\n"), src, s)
	}
	fmt.Println(string(res))
}
```
Bu noktada Go'daki `regexp` paketinin tamamını öğrenmiş oldunuz. Umarım temel methodların örneklerini inceleyerek konuyu daha iyi kavrarsınız ve böylece kendi başınıza ilginç şeyler yapabilirsiniz.

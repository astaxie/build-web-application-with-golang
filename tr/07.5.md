# 7.5 Dosyalar

Dosyalar, her bilgisayar aygıtındaki temel nesnelerdir. Web uygulamalarının da onları yoğun biçimde kullanması sizi hiç şaşırtmayacaktır. Bu bölümde Go'da dosyalar üzerinde nasıl işlem yapacağımızı öğreneceğiz.

## Dizinler

Go'da dosya işlemleriyle ilgili fonksiyonların çoğu `os` paketinde bulunur. İşte bazı dizin fonksiyonları:

- func Mkdir(name string, perm FileMode) error

	`name` adında bir dizin oluşturur. `perm` dizin izinleridir, örneğin 0777.
	
- func MkdirAll(path string, perm FileMode) error

	`path`'e göre birden fazla dizin oluşturur, örneğin `astaxie/test1/test2`.
	
- func Remove(name string) error

	`name` adındaki dizini siler. Bir dizin değilse ya da boş değilse hata döner.

- func RemoveAll(path string) error

	`path`'e göre birden fazla dizini siler. `path` tek bir yol ise dizinler silinmez. 

Kod örneği:
```Go
package main

import (
	"fmt"
	"os"
)

func main() {
	os.Mkdir("astaxie", 0777)
	os.MkdirAll("astaxie/test1/test2", 0777)
	err := os.Remove("astaxie")
	if err != nil {
		fmt.Println(err)
	}
	os.RemoveAll("astaxie")
}
```
## Dosyalar

### Dosya oluşturma ve açma

Dosya oluşturmak için iki fonksiyon vardır:

- func Create(name string) (file *File, err Error)

	`name` adında bir dosya oluşturur ve 0666 izinli, okunabilir-yazılabilir bir dosya nesnesi döner.

- func NewFile(fd uintptr, name string) *File
	
	Bir dosya oluşturur ve bir dosya nesnesi döner.


Dosya açmak için de iki fonksiyon vardır:

- func Open(name string) (file *File, err Error)

	`name` adlı dosyayı salt okunur erişimle açar; arka planda `OpenFile`'ı çağırır.

- func OpenFile(name string, flag int, perm uint32) (file *File, err Error)	

	`name` adlı dosyayı açar. `flag`, salt okunur ya da okuma-yazma gibi açma kipidir. `perm` ise dosya izinleridir.

### Dosyalara yazma

Dosyalara yazmak için kullanılan fonksiyonlar:

- func (file *File) Write(b []byte) (n int, err Error)

	Bir dosyaya byte türünde içerik yazar.

- func (file *File) WriteAt(b []byte, off int64) (n int, err Error)

	Bir dosyanın belirli bir konumuna byte türünde içerik yazar.

- func (file *File) WriteString(s string) (ret int, err Error)

	Bir dosyaya string yazar.
	
Kod örneği:
```Go
package main

import (
	"fmt"
	"os"
)

func main() {
	userFile := "astaxie.txt"
	fout, err := os.Create(userFile)		
	if err != nil {
		fmt.Println(userFile, err)
		return
	}
	defer fout.Close()
	for i := 0; i < 10; i++ {
		fout.WriteString("Sadece bir test!\r\n")
		fout.Write([]byte("Sadece bir test!\r\n"))
	}
}
```
### Dosyalardan okuma

Dosyalardan okumak için kullanılan fonksiyonlar:

- func (file *File) Read(b []byte) (n int, err Error)

	Veriyi `b`'ye okur.

- func (file *File) ReadAt(b []byte, off int64) (n int, err Error)

	`off` konumundan itibaren veriyi `b`'ye okur.

Kod örneği:
```Go
package main

import (
	"fmt"
	"os"
)

func main() {
	userFile := "asatxie.txt"
	fl, err := os.Open(userFile)		
	if err != nil {
		fmt.Println(userFile, err)
		return
	}
	defer fl.Close()
	buf := make([]byte, 1024)
	for {
		n, _ := fl.Read(buf)
		if 0 == n {
			break
		}
		os.Stdout.Write(buf[:n])
	}
}
```
### Dosyaları silme

Go, dosya ve dizinleri silmek için aynı fonksiyonu kullanır:

- func Remove(name string) Error

	`name` adlı bir dosyayı ya da dizini siler.( *** sonu `/` ile biten bir `name`, bunun bir dizin olduğunu belirtir*** )

# 7.6 Dizgiler

Web'de gördüğümüz hemen her şey (kullanıcı girdileri, veritabanı erişimi vb. dâhil) string'lerle temsil edilir. String'ler web geliştirmenin çok önemli bir parçasıdır. Birçok durumda string'leri bölmemiz, birleştirmemiz, dönüştürmemiz ve başka biçimlerde işlememiz gerekir. Bu bölümde Go standart kütüphanesindeki `strings` ve `strconv` paketlerini tanıtacağız.

## strings

Aşağıdaki fonksiyonlar `strings` paketinden gelmektedir. Daha fazla ayrıntı için resmî dokümantasyona bakınız:

- func Contains(s, substr string) bool

	`s` string'inin `substr` string'ini içerip içermediğini denetler, boolean bir değer döndürür.
```Go	
fmt.Println(strings.Contains("seafood", "foo"))
fmt.Println(strings.Contains("seafood", "bar"))
fmt.Println(strings.Contains("seafood", ""))
fmt.Println(strings.Contains("", ""))

//Çıktı:
//true
//false
//true
//true
```
- func Join(a []string, sep string) string

	Bir slice içindeki string'leri `sep` ayracıyla birleştirir.
```Go	
s := []string{"foo", "bar", "baz"}
fmt.Println(strings.Join(s, ", "))
//Çıktı:foo, bar, baz		
```			
- func Index(s, sep string) int 

	`s` string'i içinde `sep`'in indeksini bulur, bulunamazsa -1 döndürür.
```Go	
fmt.Println(strings.Index("chicken", "ken"))
fmt.Println(strings.Index("chicken", "dmr"))
//Çıktı:4
//-1
```
- func Repeat(s string, count int) string

	`s` string'ini `count` kez tekrarlar.
```Go	
fmt.Println("ba" + strings.Repeat("na", 2))
//Çıktı:banana
```
- func Replace(s, old, new string, n int) string

	`s` string'i içindeki `old` string'ini `new` string'iyle değiştirir. `n` değiştirme sayısıdır. n sıfırdan küçükse bütün eşleşmeleri değiştirir.
```Go	
fmt.Println(strings.Replace("oink oink oink", "k", "ky", 2))
fmt.Println(strings.Replace("oink oink oink", "oink", "moo", -1))
//Çıktı:oinky oinky oink
//moo moo moo
```
- func Split(s, sep string) []string

	`s` string'ini `sep` ayracına göre bir slice'a böler.
```Go	
fmt.Printf("%q\n", strings.Split("a,b,c", ","))
fmt.Printf("%q\n", strings.Split("a man a plan a canal panama", "a "))
fmt.Printf("%q\n", strings.Split(" xyz ", ""))
fmt.Printf("%q\n", strings.Split("", "Bernardo O'Higgins"))
//Çıktı:["a" "b" "c"]
//["" "man " "plan " "canal panama"]
//[" " "x" "y" "z" " "]
//[""]
```
- func Trim(s string, cutset string) string

	`s` string'inin en solunda ya da en sağında bulunuyorsa `cutset` içindeki karakterleri siler.
```Go	
fmt.Printf("[%q]", strings.Trim(" !!! Achtung !!! ", "! "))
Çıktı:["Achtung"]
```
- func Fields(s string) []string

	Boşluk öğelerini siler ve string'i boşluklara göre bir slice'a böler.
```Go	
fmt.Printf("Alanlar: %q", strings.Fields("  foo bar  baz   "))
//Çıktı:Alanlar: ["foo" "bar" "baz"]
```

## strconv

Aşağıdaki fonksiyonlar `strconv` paketinden gelmektedir. Her zamanki gibi, daha fazla ayrıntı için lütfen resmî dokümantasyona bakınız:

- Append ailesi; veriyi string'e dönüştürür ve mevcut byte slice'ın sonuna ekler.
```Go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	str := make([]byte, 0, 100)
	str = strconv.AppendInt(str, 4567, 10)
	str = strconv.AppendBool(str, false)
	str = strconv.AppendQuote(str, "abcdefg")
	str = strconv.AppendQuoteRune(str, '单')
	fmt.Println(string(str))
}
```
- Format ailesi; diğer veri türlerini string'e dönüştürür.
```Go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	a := strconv.FormatBool(false)
	b := strconv.FormatFloat(123.23, 'g', 12, 64)
	c := strconv.FormatInt(1234, 10)
	d := strconv.FormatUint(12345, 10)
	e := strconv.Itoa(1023)
	fmt.Println(a, b, c, d, e)
}
```
- Parse ailesi; string'leri diğer türlere dönüştürür.
```Go		
package main

import (
	"fmt"
	"strconv"
)

func main() {
	a, err := strconv.ParseBool("false")
	if err != nil {
		fmt.Println(err)
	}
	b, err := strconv.ParseFloat("123.23", 64)
	if err != nil {
		fmt.Println(err)
	}
	c, err := strconv.ParseInt("1234", 10, 64)
	if err != nil {
		fmt.Println(err)
	}
	d, err := strconv.ParseUint("12345", 10, 64)
	if err != nil {
		fmt.Println(err)
	}
	e := strconv.Itoa(1023)
	fmt.Println(a, b, c, d, e)
}
```

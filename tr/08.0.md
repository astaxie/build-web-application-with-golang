# 8 Web servisleri

Web servisleri, HTTP üzerinden bilgi alışverişi yapmak için XML veya JSON gibi formatları kullanmanıza olanak tanır. Örneğin, yarın Şangay'daki hava durumunu, Apple'ın güncel hisse fiyatını veya Amazon'daki bir ürünün bilgisini öğrenmek istiyorsanız, bu bilgiyi açık platformlardan almak için bir kod parçası yazabilirsiniz. Go'da bu süreç, yerel bir fonksiyonu çağırıp dönüş değerini almaya benzetilebilir.

Buradaki kilit nokta, web servislerinin platformdan bağımsız olmasıdır. Bu sayede uygulamalarınızı Linux üzerinde dağıtıp, örneğin Windows'taki ASP.NET uygulamalarıyla etkileşime girebilirsiniz; tıpkı FreeBSD üzerindeki JSP ile etkileşime girmenin bir sorun olmayacağı gibi.

REST mimarisi ve SOAP protokolü, günümüzde web servislerinin uygulanmasında en popüler stillerdir:

- REST istekleri oldukça basittir çünkü HTTP tabanlıdır. Her REST isteği aslında bir HTTP isteğidir ve sunucular istekleri farklı methodlar kullanarak işler. Birçok geliştirici zaten HTTP'ye aşina olduğu için, REST onlara tanıdık gelecektir. Go'da REST'i nasıl uygulayacağımızı 8.3. bölümde göstereceğiz.
- SOAP, W3C tarafından başlatılan, ağlar arası bilgi iletimi ve uzak bilgisayar fonksiyon çağrıları için bir standarttır. SOAP'ın sorunu, spesifikasyonunun çok uzun ve karmaşık olması, üstelik gittikçe daha da uzamasıdır. Go, işlerin basit olması gerektiğine inanır, bu yüzden SOAP'tan bahsetmeyeceğiz. Neyse ki Go, iyi performans sunan ve geliştirmesi kolay olan RPC (Remote Procedure Calls / Uzak Prosedür Çağrıları) desteği sağlıyor, bu yüzden RPC'yi Go'da nasıl uygulayacağımızı 8.4. bölümde tanıtacağız.

Go, basit ama performanslı olmayı hedefleyen 21. yüzyılın C dilidir. Bu nitelikleri göz önünde bulundurarak, 8.1. bölümde sizi Go'da soket programlamayla tanıştıracağız. Günümüzde birçok gerçek zamanlı sunucu, HTTP'nin düşük performansını aşmak için soketleri kullanıyor. HTML5'in hızlı gelişimiyle birlikte, websocket'ler artık birçok web tabanlı oyun şirketi tarafından kullanılıyor ve bundan 8.2. bölümde daha ayrıntılı bahsedeceğiz.

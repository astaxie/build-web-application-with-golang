# 8.1 Soketler

Bazı ağ uygulama geliştiricileri, alt uygulama katmanlarının tamamen soket programlamayla ilgili olduğunu söyler. Bu her durumda doğru olmayabilir, ama günümüzün pek çok web uygulaması gerçekten de soketlerden faydalanır. İnternette gezinirken tarayıcıların web sunucularıyla nasıl haberleştiğini hiç merak ettiniz mi? Ya da MSN'in sizi ve arkadaşlarınızı bir sohbet odasında nasıl bir araya getirip her mesajı gerçek zamanlı olarak nasıl ilettiğini? Bunun gibi birçok servis veri aktarmak için soket kullanır. Görüldüğü gibi soketler günümüz ağ programlamasında önemli bir yer tutuyor; bu bölümde Go'da soket kullanımını öğreneceğiz.

## Soket nedir？

Soketler Unix'ten gelir ve Unix'in temel "her şey bir dosyadır" felsefesi gereği, her şey "aç -> yaz/oku -> kapat" ile işlenebilir. Soketler de bu felsefenin bir uygulamasıdır. Tıpkı bir dosya açar gibi, soket açmak için de bir fonksiyon çağrısı vardır. Bu çağrı, sonrasında bağlantı kurma, veri aktarma gibi işlemler için kullanılabilecek bir int soket tanımlayıcısı döndürür.

Yaygın olarak kullanılan iki soket türü vardır: akış soketleri (SOCK_STREAM) ve datagram soketleri (SOCK_DGRAM). Akış soketleri TCP gibi bağlantı yönelimlidir, datagram soketleri ise UDP gibi bağlantı kurmaz.

## Soket iletişimi

Soketlerin birbiriyle nasıl haberleştiğini anlamadan önce, her soketin nasıl benzersiz olduğunu çözmemiz gerekir; aksi hâlde güvenilir bir iletişim kanalı kurmak zaten söz konusu olamaz. Her sürece amacımıza yerel olarak hizmet eden benzersiz bir PID verebiliriz, ama bu bir ağ üzerinde işe yaramaz. Neyse ki TCP/IP bu sorunu çözmemize yardımcı olur. Ağ katmanındaki IP adresleri bir host ağında benzersizdir ve "protokol + port" de host uygulamaları arasında benzersizdir. Dolayısıyla soketleri benzersiz kılmak için bu ilkelerden yararlanabiliriz.

TCP/IP tabanlı uygulamaların hepsi, kodlarında bir şekilde soket API'lerini kullanır. Ağ tabanlı uygulamaların günümüzde giderek yaygınlaştığı düşünülürse, bazı geliştiricilerin "her şey soketlerle ilgilidir" demesine şaşmamak gerek.

## Soket temel bilgisi

Soketlerin TCP soketleri ve UDP soketleri olmak üzere iki türü olduğunu biliyoruz. TCP ve UDP birer protokoldür ve daha önce belirtildiği gibi, benzersiz bir soket için bir IP adresine ve port numarasına da ihtiyacımız var.

### IPv4

Küresel internet, protokolü olarak TCP/IP kullanır; burada IP ağ katmanıdır ve TCP/IP'nin çekirdek bir parçasıdır. IPv4, sürümünün 4 olduğunu belirtir; bugüne kadarki altyapı geliştirmesi 30 yılı aşkın bir süreye yayılmıştır.

Bir IPv4 adresindeki bit sayısı 32'dir, bu da 2^32 cihazın internete benzersiz şekilde bağlanabileceği anlamına gelir. İnternetin hızlı gelişimi nedeniyle, son yıllarda IP adresleri zaten tükenmeye başlamıştır.

Adres biçimi: `127.0.0.1`, `172.122.121.111`.

### IPv6

IPv6, internetin bir sonraki sürümü ya da yeni nesildir. IPv4'e özgü pek çok sorunu çözmek üzere geliştirilmektedir. IPv6 kullanan cihazların adresi 128 bit uzunluğundadır, dolayısıyla benzersiz adres kıtlığı konusunda hiçbir zaman endişelenmemize gerek kalmaz. Bunu bir perspektife oturtmak gerekirse, IPv6 ile dünya üzerindeki her metrekare için 1000'den fazla IP adresine sahip olabilirsiniz. Eşler arası bağlantı, servis kalitesi (QoS), güvenlik, çoklu yayın (multiple broadcast) gibi diğer sorunlar da iyileştirilmiştir.

Adres biçimi: `2002:c0e8:82e7:0:0:0:c0e8:82e7`.

### Go'da IP türleri

Go'daki `net` paketi, ağ programlaması için birçok tür, fonksiyon ve method sağlar. IP'nin tanımı şu şekildedir:

	type IP []byte

`ParseIP(s string) IP` fonksiyonu, IPv4 veya IPv6 biçimini bir IP'ye dönüştürür:

	package main
	import (
		"net"
		"os"
		"fmt"
	)
	func main() {
		if len(os.Args) != 2 {
			fmt.Fprintf(os.Stderr, "Usage: %s ip-addr\n", os.Args[0])
			os.Exit(1)
		}
		name := os.Args[1]
		addr := net.ParseIP(name)
		if addr == nil {
			fmt.Println("Invalid address")
		} else {
			fmt.Println("The address is ", addr.String())
		}
		os.Exit(0)
	}

Bu fonksiyon, verilen IP adresine karşılık gelen IP biçimini döndürür.

## TCP soketi

Bir ağ portu üzerinden bir web servisini nasıl ziyaret edeceğimizi bildiğimizde ne yapabiliriz? Bir istemci olarak, belirlenen bir ağ portuna bir istek gönderip yanıtını alabiliriz; bir sunucu olarak ise bir servisi belirlenen bir ağ portuna bağlamamız, istemcilerin isteklerini beklememiz ve bir yanıt sağlamamız gerekir.

Go'nun `net` paketinde, bu tür istemci/sunucu etkileşimini kolaylaştıran `TCPConn` adlı bir tür bulunur. Bu türün iki temel fonksiyonu vardır:

	func (c *TCPConn) Write(b []byte) (n int, err os.Error)
	func (c *TCPConn) Read(b []byte) (n int, err os.Error)

`TCPConn`, veri okuma ve yazma için hem istemci hem de sunucu tarafından kullanılabilir.

TCP adres bilgisini temsil etmek için bir `TCPAddr`'a da ihtiyacımız var:

	type TCPAddr struct {
		IP IP
		Port int
	}

Go'da bir `TCPAddr` elde etmek için `ResolveTCPAddr` fonksiyonunu kullanırız:

	func ResolveTCPAddr(net, addr string) (*TCPAddr, os.Error)

- `net` argümanı, sırasıyla yalnızca IPv4, yalnızca IPv6 ya da her ikisini de belirten "tcp4", "tcp6" veya "tcp" değerlerinden biri olabilir.
- `addr`, "www.google.com:80" veya "127.0.0.1:22" gibi bir alan adı veya IP adresi olabilir.

### TCP istemcisi

Go istemcileri, `net` paketindeki `DialTCP` fonksiyonunu kullanarak bir TCP bağlantısı oluşturur; bu fonksiyon bir `TCPConn` nesnesi döndürür. Bağlantı kurulduktan sonra sunucu da mevcut bağlantı için aynı türde bir bağlantı nesnesine sahip olur ve istemci ile sunucu birbirleriyle veri alışverişine başlayabilir. Genel olarak, istemciler bir `TCPConn` aracılığıyla sunuculara istek gönderir ve sunucu yanıtından bilgi alır; sunucular ise istemci isteklerini okuyup ayrıştırır, ardından geri bildirim döndürür. Bu bağlantı, istemci veya sunucu tarafından kapatılana kadar geçerli kalır. Bağlantı oluşturmak için kullanılan fonksiyon şu şekildedir:

	func DialTCP(net string, laddr, raddr *TCPAddr) (c *TCPConn, err os.Error)

- `net` argümanı, sırasıyla yalnızca IPv4, yalnızca IPv6 ya da her ikisini de belirten "tcp4", "tcp6" veya "tcp" değerlerinden biri olabilir.
- `laddr` yerel adresi temsil eder, çoğu durumda `nil` olarak ayarlanır.
- `raddr` uzak adresi temsil eder.

Bir HTTP isteğine dayanarak bir istemcinin sunucuya bağlantı isteğini simüle eden basit bir örnek yazalım. Basit bir HTTP istek başlığına ihtiyacımız var:

	"HEAD / HTTP/1.0\r\n\r\n"

Sunucu yanıt bilgisinin biçimi şuna benzer olabilir:

	HTTP/1.0 200 OK
	ETag: "-9985996"
	Last-Modified: Thu, 25 Mar 2010 17:51:10 GMT
	Content-Length: 18074
	Connection: close
	Date: Sat, 28 Aug 2010 00:43:48 GMT
	Server: lighttpd/1.4.23

İstemci kodu:

	package main

	import (
		"fmt"
		"io/ioutil"
		"net"
		"os"
	)

	func main() {
		if len(os.Args) != 2 {
			fmt.Fprintf(os.Stderr, "Usage: %s host:port ", os.Args[0])
			os.Exit(1)
		}
		service := os.Args[1]
		tcpAddr, err := net.ResolveTCPAddr("tcp4", service)
		checkError(err)
		conn, err := net.DialTCP("tcp", nil, tcpAddr)
		checkError(err)
		_, err = conn.Write([]byte("HEAD / HTTP/1.0\r\n\r\n"))
		checkError(err)
		result, err := ioutil.ReadAll(conn)
		checkError(err)
		fmt.Println(string(result))
		os.Exit(0)
	}
	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error: %s", err.Error())
			os.Exit(1)
		}
	}

Yukarıdaki örnekte, bir `tcpAddr` elde etmek için kullanıcı girdisini `net.ResolveTCPAddr` fonksiyonunun `service` argümanı olarak kullanıyoruz. `tcpAddr`'ı `DialTCP` fonksiyonuna geçirerek bir TCP bağlantısı olan `conn`'u oluşturuyoruz. Ardından `conn`'u kullanarak sunucuya istek bilgisi gönderebiliriz. Son olarak, sunucu yanıtını içeren `conn`'daki tüm içeriği okumak için `ioutil.ReadAll`'ı kullanıyoruz.

### TCP sunucusu

Artık bir TCP istemcimiz var. `net` paketini kullanarak bir TCP sunucusu da yazabiliriz. Sunucu tarafında, servisimizi belirli, kullanılmayan bir porta bağlamamız ve gelen istemci isteklerini dinlememiz gerekir.

	func ListenTCP(net string, laddr *TCPAddr) (l *TCPListener, err os.Error)
	func (l *TCPListener) Accept() (c Conn, err os.Error)

Burada gereken argümanlar, daha önce kullandığımız `DialTCP` fonksiyonunun gerektirdiği argümanlarla aynıdır. 7777 portunu kullanan bir zaman senkronizasyon servisi uygulayalım:

	package main

	import (
		"fmt"
		"net"
		"os"
		"time"
	)

	func main() {
		service := ":7777"
		tcpAddr, err := net.ResolveTCPAddr("tcp4", service)
		checkError(err)
		listener, err := net.ListenTCP("tcp", tcpAddr)
		checkError(err)
		for {
			conn, err := listener.Accept()
			if err != nil {
				continue
			}
			daytime := time.Now().String()
			conn.Write([]byte(daytime)) // don't care about return value
			conn.Close()                // we're finished with this client
		}
	}
	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error: %s", err.Error())
			os.Exit(1)
		}
	}

Servis başlatıldıktan sonra istemci isteklerini bekler. Bir istemci isteği aldığında bunu `Accept` eder ve istemciye geçerli zaman bilgisini içeren bir yanıt döndürür. Şunu belirtmekte fayda var: `for` döngüsünde bir hata oluştuğunda servis çıkış yapmak yerine çalışmaya devam eder. Çökmek yerine sunucu, hatayı bir sunucu hata günlüğüne kaydeder.

Ancak yukarıdaki kod hâlâ yeterince iyi değil. Eşzamanlı isteklerin kabul edilmesini sağlayacak olan goroutine'lerden faydalanmadık. Şimdi bunu yapalım:

	package main

	import (
		"fmt"
		"net"
		"os"
		"time"
	)

	func main() {
		service := ":1200"
		tcpAddr, err := net.ResolveTCPAddr("tcp4", service)
		checkError(err)
		listener, err := net.ListenTCP("tcp", tcpAddr)
		checkError(err)
		for {
			conn, err := listener.Accept()
			if err != nil {
				continue
			}
			go handleClient(conn)
		}
	}

	func handleClient(conn net.Conn) {
		defer conn.Close()
		daytime := time.Now().String()
		conn.Write([]byte(daytime)) // don't care about return value
		// we're finished with this client
	}
	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error: %s", err.Error())
			os.Exit(1)
		}
	}

İş sürecimizi `handleClient` fonksiyonuna ayırıp `go` anahtar kelimesini kullanarak, servisimizde eşzamanlılığı çoktan uygulamış olduk. Bu, goroutine'lerin gücünün ve sadeliğinin güzel bir örneğidir.

Bazılarınız şöyle düşünüyor olabilir: bu sunucu anlamlı bir şey yapmıyor. Ya tek bir bağlantı üzerinden farklı zaman biçimleri için birden çok istek göndermemiz gerekseydi? Bunu nasıl yapardık?

	package main

	import (
		"fmt"
		"net"
		"os"
		"time"
		"strconv"
	)

	func main() {
		service := ":1200"
		tcpAddr, err := net.ResolveTCPAddr("tcp4", service)
		checkError(err)
		listener, err := net.ListenTCP("tcp", tcpAddr)
		checkError(err)
		for {
			conn, err := listener.Accept()
			if err != nil {
				continue
			}
			go handleClient(conn)
		}
	}

	func handleClient(conn net.Conn) {
		conn.SetReadDeadline(time.Now().Add(2 * time.Minute)) // set 2 minutes timeout
		request := make([]byte, 128) // set maximum request length to 128B to prevent flood based attacks
		defer conn.Close()  // close connection before exit
		for {
			read_len, err := conn.Read(request)

			if err != nil {
				fmt.Println(err)
				break
			}

    		if read_len == 0 {
    			break // connection already closed by client
    		} else if string(request[:read_len]) == "timestamp" {
    			daytime := strconv.FormatInt(time.Now().Unix(), 10)
    			conn.Write([]byte(daytime))
    		} else {
    			daytime := time.Now().String()
    			conn.Write([]byte(daytime))
    		}
		}
	}

	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error: %s", err.Error())
			os.Exit(1)
		}
	}

Bu örnekte, istemci isteklerini sürekli okumak için `conn.Read()`'i kullanıyoruz. Bağlantıyı kapatamayız çünkü istemciler birden fazla istek gönderebilir. `conn.SetReadDeadline()` ile ayarladığımız zaman aşımı sayesinde, bağlantı belirlediğimiz süre sonunda otomatik olarak kapanır. Süre dolduğunda programımız `for` döngüsünden çıkar. `request`'in, taşma (flood) saldırılarını önlemek için maksimum bir boyut sınırlamasıyla oluşturulması gerektiğine dikkat edin.

### TCP bağlantılarını kontrol etme

TCP kontrol fonksiyonları:

	func DialTimeout(net, addr string, timeout time.Duration) (Conn, error)

Bağlantıların zaman aşımını ayarlama. Bunlar hem istemcilerde hem de sunucularda kullanıma uygundur:

	func (c *TCPConn) SetReadDeadline(t time.Time) error
	func (c *TCPConn) SetWriteDeadline(t time.Time) error

Bir bağlantının yazma/okuma zaman aşımını ayarlama:

	func (c *TCPConn) SetKeepAlive(keepalive bool) os.Error

Bağlantı zaman aşımlarınızın ne kadar uzun olmasını istediğinizi düşünmeye zaman ayırmakta fayda var. Uzun bağlantılar, bağlantı oluşturmayla ilgili yükü azaltabilir ve verileri sık sık alışveriş etmesi gereken uygulamalar için uygundur.

Daha ayrıntılı bilgi için Go'nun `net` paketinin resmi dökümantasyonuna bakmanız yeterli.

## UDP soketleri

UDP soketi ile TCP soketi arasındaki tek fark, sunucu tarafında birden çok isteği işleme yöntemidir. Bu, UDP'nin `Accept` gibi bir fonksiyona sahip olmamasından kaynaklanır. Diğer tüm fonksiyonların `UDP` karşılıkları vardır; yukarıda bahsedilen fonksiyonlarda `TCP`'yi `UDP` ile değiştirmeniz yeterli.

	func ResolveUDPAddr(net, addr string) (*UDPAddr, os.Error)
	func DialUDP(net string, laddr, raddr *UDPAddr) (c *UDPConn, err os.Error)
	func ListenUDP(net string, laddr *UDPAddr) (c *UDPConn, err os.Error)
	func (c *UDPConn) ReadFromUDP(b []byte) (n int, addr *UDPAddr, err os.Error
	func (c *UDPConn) WriteToUDP(b []byte, addr *UDPAddr) (n int, err os.Error)

UDP istemci kod örneği:

	package main

	import (
		"fmt"
		"net"
		"os"
	)

	func main() {
		if len(os.Args) != 2 {
			fmt.Fprintf(os.Stderr, "Usage: %s host:port", os.Args[0])
			os.Exit(1)
		}
		service := os.Args[1]
		udpAddr, err := net.ResolveUDPAddr("udp4", service)
		checkError(err)
		conn, err := net.DialUDP("udp", nil, udpAddr)
		checkError(err)
		_, err = conn.Write([]byte("anything"))
		checkError(err)
		var buf [512]byte
		n, err := conn.Read(buf[0:])
		checkError(err)
		fmt.Println(string(buf[0:n]))
		os.Exit(0)
	}
	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error ", err.Error())
			os.Exit(1)
		}
	}

UDP sunucu kod örneği:

	package main

	import (
		"fmt"
		"net"
		"os"
		"time"
	)

	func main() {
		service := ":1200"
		udpAddr, err := net.ResolveUDPAddr("udp4", service)
		checkError(err)
		conn, err := net.ListenUDP("udp", udpAddr)
		checkError(err)
		for {
			handleClient(conn)
		}
	}
	func handleClient(conn *net.UDPConn) {
		var buf [512]byte
		_, addr, err := conn.ReadFromUDP(buf[0:])
		if err != nil {
			return
		}
		daytime := time.Now().String()
		conn.WriteToUDP([]byte(daytime), addr)
	}
	func checkError(err error) {
		if err != nil {
			fmt.Fprintf(os.Stderr, "Fatal error ", err.Error())
			os.Exit(1)
		}
	}

## Özet

TCP ve UDP soketlerini kullanan bazı basit programları anlatıp kodlayarak, Go'nun soket programlamaya mükemmel destek sağladığını ve bunların eğlenceli ve kullanımı kolay olduğunu görebiliyoruz. Go ayrıca yüksek performanslı soket uygulamaları oluşturmak için birçok fonksiyon sağlar.

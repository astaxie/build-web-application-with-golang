# 9.6 Veri şifreleme ve çözme

Önceki bölümde şifrelerin güvenli biçimde nasıl saklanacağı anlatıldı, ancak bazen veritabanımızda saklanan bazı hassas şifreli verileri değiştirmek gerekebilir. Veri çözme (decryption) gerektiğinde, daha önce ele aldığımız tek yönlü hashleme tekniklerini değil, simetrik bir şifreleme algoritmasını kullanmalıyız.

## Gelişmiş şifreleme ve çözme

Go dili, `crypto` paketinde simetrik şifreleme algoritmalarını destekler. Ne yaptığınızı bilmiyorsanız, [GCM modunda](https://en.wikipedia.org/wiki/Galois/Counter_Mode) AES dışında hiçbir şey kullanmayın!

- `crypto/aes` paketi: AES (Advanced Encryption Standard), Rijndael şifreleme yöntemi olarak da bilinir ve A.B.D. federal hükümeti tarafından blok şifreleme standardı olarak kullanılır.

Aşağıdaki örnekte, verinin GCM modunda AES kullanılarak nasıl şifreleneceğini gösteriyoruz:

	package main

	import (
		"crypto/aes"
		"crypto/cipher"
		"crypto/rand"
		"errors"
		"fmt"
		"io"
		"log"
	)

	func main() {
		text := []byte("My name is Astaxie")
		key := []byte("the-key-has-to-be-32-bytes-long!")

		ciphertext, err := encrypt(text, key)
		if err != nil {
			// TODO: Hatayı düzgün şekilde işle
			log.Fatal(err)
		}
		fmt.Printf("%s => %x\n", text, ciphertext)

		plaintext, err := decrypt(ciphertext, key)
		if err != nil {
			// TODO: Hatayı düzgün şekilde işle
			log.Fatal(err)
		}
		fmt.Printf("%x => %s\n", ciphertext, plaintext)
	}

	func encrypt(plaintext []byte, key []byte) ([]byte, error) {
		c, err := aes.NewCipher(key)
		if err != nil {
			return nil, err
		}

		gcm, err := cipher.NewGCM(c)
		if err != nil {
			return nil, err
		}

		nonce := make([]byte, gcm.NonceSize())
		if _, err = io.ReadFull(rand.Reader, nonce); err != nil {
			return nil, err
		}

		return gcm.Seal(nonce, nonce, plaintext, nil), nil
	}

	func decrypt(ciphertext []byte, key []byte) ([]byte, error) {
		c, err := aes.NewCipher(key)
		if err != nil {
			return nil, err
		}

		gcm, err := cipher.NewGCM(c)
		if err != nil {
			return nil, err
		}

		nonceSize := gcm.NonceSize()
		if len(ciphertext) < nonceSize {
			return nil, errors.New("ciphertext too short")
		}

		nonce, ciphertext := ciphertext[:nonceSize], ciphertext[nonceSize:]
		return gcm.Open(nil, nonce, ciphertext, nil)
	}

Yukarıdaki `aes.NewCipher` fonksiyonu çağrıldığında (bu fonksiyonun []byte tipindeki key parametresi sırasıyla AES-128, AES-192 veya AES-256 algoritmalarına karşılık gelecek şekilde 16, 24 veya 32 uzunluğunda olmalıdır), üç fonksiyon uygulayan bir `cipher.Block` interface'i döner:

	type Block interface {
		// BlockSize cipher'ın blok boyutunu döner.
		BlockSize() int

		// Encrypt, src içindeki ilk bloğu şifreleyip dst'ye yazar.
		// Dst ve src aynı belleği gösterebilir.
		Encrypt(dst, src []byte)

		// Decrypt, src içindeki ilk bloğun şifresini çözüp dst'ye yazar.
		// Dst ve src aynı belleği gösterebilir.
		Decrypt(dst, src []byte)
	}

Bu üç fonksiyon şifreleme ve şifre çözme işlemlerini gerçekleştirir; daha ayrıntılı açıklama için Go dökümantasyonuna bakın.

## Özet

Bu bölüm, web uygulamanızın şifreleme ve şifre çözme ihtiyaçlarına göre farklı biçimlerde kullanılabilecek şifreleme algoritmalarını anlatır. Temel güvenlik gereksinimleri olan uygulamalar için GCM modunda AES kullanılması önerilir.

# 10.3 Uluslararası siteler

Önceki bölümde yerel ayar yapılandırma dosyaları kullanarak yerelleştirilmiş kaynaklarla nasıl başa çıkılacağını anlattık. Peki metin çevirileri, saat ve tarihler, sayılar gibi *birden fazla* yerelleştirilmiş kaynakla başa çıkmamız gerekirse ne yapabiliriz? Bu bölüm bu konuları tek tek ele alacak.

## Birden fazla yerel ayar paketini yönetmek

Bir uygulama geliştirirken genellikle yapmanız gereken ilk şey birden fazla dili destekleyip desteklemeyeceğinize karar vermektir. Birden fazla dili desteklemeye karar verirseniz, gelecekte daha fazla dil eklemeyi kolaylaştıracak bir organizasyon yapısı geliştirmeniz gerekir. Bunu yapmanın bir yolu, ilgili tüm yerel ayar dosyalarını `config/locales` dizini gibi bir yerde bir araya toplamaktır. Diyelim ki hem Çince hem de İngilizceyi desteklemek istiyorsunuz. Bu durumda en.json ve zh.json yerel ayar dosyalarının ikisini de yukarıda bahsedilen klasöre yerleştirirsiniz. İçerikleri muhtemelen şöyle görünecektir:

	# zh.json

	{
	"zh": {
		"submit": "提交",
		"create": "创建"
		}
	}

	# en.json

	{
	"en": {
		"submit": "Submit",
		"create": "Create"
		}
	}

Web uygulamalarımızı uluslararasılaştırmamıza yardımcı olması için bazı üçüncü parti Go paketleri kullanmaya karar verdik. [go-i18n](https://github.com/astaxie/go-i18n) örneğinde ( ***daha gelişmiş bir i18n paketini [burada](https://github.com/beego/i18n) bulabilirsiniz*** ), önce tüm yerel ayar dosyalarımızı yüklemesi için `config/locales` dizinimizi kaydetmemiz gerekir:

	Tr := i18n.NewLocale()
	Tr.LoadPath("config/locales")

Bu paketin kullanımı basittir. Çalıştığını şu şekilde test edebiliriz:

	fmt.Println(Tr.Translate("submit"))
	//Çıktı: "submit"
	Tr.SetLocale("zn")
	fmt.Println(Tr.Translate("submit"))
	//Çıktı: "递交"

## Yerel paketi otomatik yükleme

Az önce özel dil paketlerinin nasıl otomatik olarak yükleneceğini anlattık. Aslında `go-i18n` kütüphanesi, saat ve para birimi biçimleri gibi bir dizi öntanımlı biçimlendirme bilgisiyle önceden yüklenmiş gelir. Bu öntanımlı yapılandırmalar, kullanıcılar tarafından ihtiyaçlarına göre geçersiz kılınabilir ve özelleştirilebilir. Şu süreci ele alalım:

	//Aşağıda `go-i18n/locales` altında yer alan öntanımlı yapılandırma dosyalarını yükle

	//Dosya zh.json, en-json, en-US.json vb. şeklinde adlandırılmalı, böylece daha fazla dili sürekli destekleyebiliriz

	func (il *IL) loadDefaultTranslations(dirPath string) error {
		dir, err := os.Open(dirPath)
		if err != nil {
			return err
		}
		defer dir.Close()

		names, err := dir.Readdirnames(-1)
		if err != nil {
			return err
		}

		for _, name := range names {
			fullPath := path.Join(dirPath, name)

			fi, err := os.Stat(fullPath)
			if err != nil {
				return err
			}

			if fi.IsDir() {
				if err := il.loadTranslations(fullPath); err != nil {
					return err
				}
			} else if locale := il.matchingLocaleFromFileName(name); locale != "" {
				file, err := os.Open(fullPath)
				if err != nil {
					return err
				}
				defer file.Close()

				if err := il.loadTranslation(file, locale); err != nil {
					return err
				}
			}
		}

		return nil
	}

Yukarıdaki kodu tüm öntanımlı çevirilerimizi yüklemek için kullandıktan sonra, bir yerel ayarı seçip kullanmak için aşağıdaki kodu kullanabiliriz:

	fmt.Println(Tr.Time(time.Now()))
	//Çıktı: 2009年1月08日 星期四 20:37:58 CST

	fmt.Println(Tr.Time(time.Now(),"long"))
	//Çıktı: 2009年1月08日

	fmt.Println(Tr.Money(11.11))
	//Çıktı: ¥11.11

## Şablon mapfunc

Yukarıda, birden fazla dil paketini yönetmenin ve entegre etmenin bir yolunu sunduk. Uyguladığımız fonksiyonların bir kısmı mantık katmanına dayanır, örneğin: "Tr.Translate", "Tr.Time", "Tr.Money" ve benzerleri. Mantık katmanında, bu fonksiyonları (gerekli parametreleri sağladıktan sonra) çevirilerinizi uygulamak için kullanabilir, sonuçları render zamanında doğrudan şablon katmanına çıktı olarak verebiliriz. Bu fonksiyonları *doğrudan* şablon katmanında kullanmak istersek ne yapabiliriz? Unuttuysanız hatırlatalım, kitabın başlarında Go şablonlarının özel şablon fonksiyonlarını desteklediğinden bahsetmiştik. Aşağıdaki kod mapfunc'ın ne kadar kolay uygulanabileceğini gösteriyor:

1 metin bilgisi

Bir mapfunc uygulayan basit bir metin dönüştürme fonksiyonu aşağıda görülebilir. Uygun çevirileri gerçekleştirmek için `Tr.Translate` kullanır:

	func I18nT(args ...interface{}) string {
		ok := false
		var s string
		if len(args) == 1 {
			s, ok = args[0].(string)
		}
		if !ok {
			s = fmt.Sprint(args...)
		}
		return Tr.Translate(s)
	}

Fonksiyonu şöyle kaydederiz:

	t.Funcs(template.FuncMap{"T": I18nT})

Ardından şablonunuzdan kullanın:

	{{.V.Submit | T}}


2. Tarih ve saat

Tarihler ve saatler, çevirilerini gerçekleştirmek için `Tr.Time` fonksiyonunu çağırır. mapfunc şu şekilde uygulanır:

	func I18nTimeDate(args ...interface{}) string {
		ok := false
		var s string
		if len(args) == 1 {
			s, ok = args[0].(string)
		}
		if !ok {
			s = fmt.Sprint(args...)
		}
		return Tr.Time(s)
	}

Fonksiyonu şöyle kaydedin:

	t.Funcs(template.FuncMap{"TD": I18nTimeDate})

Ardından şablonunuzdan kullanın:

	{{.V.Now | TD}}

3 Para birimi bilgisi

Para birimleri, para dönüştürmek için `Tr.Money` fonksiyonunu kullanır. mapFunc şu şekilde uygulanır:

	func I18nMoney(args ...interface{}) string {
		ok := false
		var s string
		if len(args) == 1 {
			s, ok = args[0].(string)
		}
		if !ok {
			s = fmt.Sprint(args...)
		}
		return Tr.Money(s)
	}

Fonksiyonu şöyle kaydedin:

	t.Funcs(template.FuncMap{"M": I18nMoney})

Ardından şablonunuzdan kullanın:

	{{.V.Money | M}}

## Özet

Bu bölümde web uygulamalarımızda birden fazla dil paketini nasıl uygulayacağımızı öğrendik. Özel dil paketleri sayesinde uygulamalarımızı yalnızca kolayca uluslararasılaştırmakla kalmayıp, (bir yapılandırma dosyası kullanarak) başka dillerin eklenmesini de kolaylaştırabildiğimizi gördük. go-i18n paketi öntanımlı olarak saat, para birimi vb. için bazı ortak yapılandırmalar sağlar; bu da kullanımı oldukça kolaylaştırır. Bu fonksiyonların mapping fonksiyonları kullanılarak şablonlarımızdan doğrudan da kullanılabildiğini öğrendik; çevrilen her dize doğrudan şablonlarımıza pipe edilebilir. Bu, web uygulamalarımızın minimum çabayla birden fazla dili desteklemesini sağlar.

# 13.2 Yönlendirici ayarları

## HTTP yönlendirme

HTTP yönlendirme bileşeni, HTTP isteklerini karşılık gelen bir fonksiyona veya `struct` method'una eşlemekten sorumludur. Yönlendirici, gelen isteklerden iki temel bilgi alır:

-Kullanıcının istediği yol (örneğin `/user/123,/article/123`) ve buna eşlik eden sorgu dizgileri veya parametreler (örneğin `?id=11`)
-HTTP istek method'u (GET, POST, PUT, DELETE, PATCH vb.)

Yönlendirici daha sonra isteği, o belirli HTTP method'u ve yol için kayıtlı olan handler fonksiyonuna (controller katmanı) iletir.

## Öntanımlı yönlendirme uygulaması

Bölüm 3.4'te Go'nun `http` paketini ayrıntılı olarak tanıtmıştık; bu, yönlendirmenin nasıl tasarlanıp uygulanacağını da içeriyordu. Burada, yönlendirme sürecini gösteren bir örneğe tekrar göz atıyoruz:

	func fooHandler(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "Hello, %q", html.EscapeString(r.URL.Path))
	}

	http.Handle("/foo", fooHandler)

	http.HandleFunc("/bar", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "Hello, %q", html.EscapeString(r.URL.Path))
	})

	log.Fatal(http.ListenAndServe(":8080", nil))
	
Yukarıdaki örnek, `http.ListenAndServe` çağrısındaki `nil` parametresiyle örtük olarak belirtilen, `http`'nin `DefaultServeMux` adlı öntanımlı mux'ını çağırır. `http.Handle` fonksiyonu iki parametre alır: birinci parametre, kullanıcıların erişmesini istediğiniz kaynaktır ve URL yolu (`r.URL.Path` içinde saklanır) ile belirtilir; ikinci argüman ise bu yola bir handler fonksiyonu bağlar. Yönlendiricinin iki temel görevi vardır:

- Yönlendirme bilgisini eklemek ve saklamak
- İstekleri işlenmek üzere bir handler fonksiyonuna iletmek

Öntanımlı olarak, Go'da rotalar `http.Handle` ve `http.HandleFunc` türleri ile ele alınır ve alttaki `DefaultServeMux.Handle(pattern string, handler Handler)` fonksiyonu aracılığıyla öntanımlı olarak kaydedilir. Bu fonksiyon, kaynak yollarını handler'larla eşler ve bunları bir `map[string]muxEntry` map'inde saklar. Bu, yukarıda bahsettiğimiz ilk görevdir.

Uygulama çalışırken, Go sunucusu bir portu dinler. Bir tcp bağlantısı aldığında, bunu işlemek için bir `Handler` kullanır. Daha önce belirtildiği gibi, yukarıdaki örnekte `Handler` `nil` olduğundan, öntanımlı yönlendirici `http.DefaultServeMux` kullanılır. Daha önce saklanmış rotaların map'ini kullanan `DefaultServeMux.ServeHTTP`, isteği eşleşen yola sahip ilk handler'a gönderir. Bu, yönlendiricinin ikinci görevidir.

	for k, v := range mux.m {
		if !pathMatch(k, path) {
			continue
		}
		if h == nil || len(k) > n {
			n = len(k)
			h = v.h
		}
	}

## Beego ile yönlendirme

Şu anda, çoğu Go web uygulaması yönlendirmesini `http`'nin öntanımlı yönlendiricisine dayandırır; ancak bunun bazı sınırlamaları vardır:

- Parametreli dinamik rotaları desteklemez, örneğin `the/user/:UID`
- REST için iyi bir desteği yoktur. Erişim method'ları kısıtlanamaz; örneğin yukarıdaki örnekte, kullanıcılar `/foo`'ya eriştiklerinde GET, POST, DELETE ve HEAD gibi HTTP method'larından herhangi birini kullanabilirler.
- Büyük uygulamalarda yönlendirme kuralları tekrarlayıcı ve hantal hale gelebilir. Şahsen, neredeyse otuz yönlendirme kuralından oluşan basit web API'leri geliştirdim; oysa bu kurallar method struct'ları kullanılarak daha da basitleştirilebilirdi.

Beego çatısının yönlendiricisi, REST paradigmasını dikkate alarak ve rotaların ile isteklerin saklanmasını ve iletilmesini basitleştirerek bu sınırlamaların üstesinden gelmek üzere tasarlanmıştır.

### Rotaların saklanması

Öntanımlı yönlendiricinin ilk sınırlamasını gidermek için, dinamik URL parametrelerini destekleyebilmemiz gerekir. İkinci ve üçüncü noktalar için ise alternatif bir yaklaşım benimsiyoruz: REST method'larını handler fonksiyonlarına değil, struct method'larına eşleyip istekleri bu struct'a yönlendiriyoruz. Bu şekilde, iletilen bir istek HTTP method'una göre işlenebilir.

Yukarıdaki fikirlere dayanarak iki veri türü tasarladık: yolu ve karşılık gelen `controllerType` struct'ını bir `reflect.Type` türü olarak saklayan `controllerInfo`, ve belirtilen Beego uygulaması için yönlendirme bilgisini saklayan `ControllerRegistor`.

	type controllerInfo struct {
		regex          *regexp.Regexp
		params         map[int]string
		controllerType reflect.Type
	}

	type ControllerRegistor struct {
		routers     []*controllerInfo
		Application *App
	}

ControllerRegistor'ın dış interface'i şu method'u içerir:

	func(p *ControllerRegistor) Add(pattern string, c ControllerInterface)

Ayrıntılı uygulaması şu şekildedir:

	func (p *ControllerRegistor) Add(pattern string, c ControllerInterface) {
		parts := strings.Split(pattern, "/")
	
		j := 0
		params := make(map[int]string)
		for i, part := range parts {
			if strings.HasPrefix(part, ":") {
				expr := "([^/]+)"

				//kullanıcı öntanımlı ifadeyi geçersiz kılmayı seçebilir
				// expressjs'e benzer şekilde: '/user/:id([0-9]+)'
 
				if index := strings.Index(part, "("); index != -1 {
					expr = part[index:]
					part = part[:index]
				}
				params[j] = part
				parts[i] = expr
				j++
			}
		}
	
		//url pattern'ini, parametreler
		//düzenli ifadelerle değiştirilmiş olarak yeniden oluştur. Sonra regex'i derle.

		pattern = strings.Join(parts, "/")
		regex, regexErr := regexp.Compile(pattern)
		if regexErr != nil {

			//TODO panic'ten kaçınmak için burada hata yakalama ekle
			panic(regexErr)
			return
		}
	
		//şimdi Route'u oluştur
		t := reflect.Indirect(reflect.ValueOf(c)).Type()
		route := &controllerInfo{}
		route.regex = regex
		route.params = params
		route.controllerType = t
	
		p.routers = append(p.routers, route)
	
	}
	
### Statik yönlendirme

Yukarıdaki örneğimizde dinamik yönlendirmeyi uyguladık. Öntanımlı olarak, Go'nun `http` paketi, bir `Handler` döndüren `http.FileServer` ile statik dosyaların sunulmasını destekler. Kendi özel yönlendiricimizi uyguladığımız için, statik dosyaları ele almanın bir yoluna da ihtiyacımız olacak. Beego'nun statik klasör yolu, URL'yi karşılık gelen yollara eşleyen `StaticDir` adlı bir global değişkende saklanır. `SetStaticPath`'in uygulaması aşağıda görülebilir:

	func (app *App) SetStaticPath(url string, path string) *App {
		StaticDir[url] = path
		return app
	}

Uygulamanın statik rotaları şu şekilde ayarlanabilir:

	beego.SetStaticPath("/img", "/static/img")

### Rotaların iletilmesi

Rotaları, `ControllerRegistor` içinde bulunan iletme bilgisine dayanarak iletebiliriz. Ayrıntılı uygulama aşağıdaki kod parçasında görülebilir:

	// AutoRoute
	func (p *ControllerRegistor) ServeHTTP(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if err := recover(); err != nil {
				if !RecoverPanic {
					// panic'e geri dön
					panic(err)
				} else {
					Critical("Handler crashed with error", err)
					for i := 1; ; i += 1 {
						_, file, line, ok := runtime.Caller(i)
						if !ok {
							break
						}
						Critical(file, line)
					}
				}
			}
		}()
		var started bool
		for prefix, staticDir := range StaticDir {
			if strings.HasPrefix(r.URL.Path, prefix) {
				file := staticDir + r.URL.Path[len(prefix):]
				http.ServeFile(w, r, file)
				started = true
				return
			}
		}
		requestPath := r.URL.Path
	
		//eşleşen bir Route bul
		for _, route := range p.routers {
	
			//Route pattern'inin url ile eşleşip eşleşmediğini kontrol et
			if !route.regex.MatchString(requestPath) {
				continue
			}
	
			//alt eşleşmeleri (parametreleri) al
			matches := route.regex.FindStringSubmatch(requestPath)
	
			//Route'un URL pattern'iyle eşleştiğini tekrar kontrol et.
			if len(matches[0]) != len(requestPath) {
				continue
			}
	
			params := make(map[string]string)
			if len(route.params) > 0 {
				//url parametrelerini sorgu parametreleri map'ine ekle
				values := r.URL.Query()
				for i, match := range matches[1:] {
					values.Add(route.params[i], match)
					params[route.params[i]] = match
				}
	
				//sorgu parametrelerini yeniden birleştir ve RawQuery'ye ekle
				r.URL.RawQuery = url.Values(values).Encode() + "&" + r.URL.RawQuery
				//r.URL.RawQuery = url.Values(values).Encode()
			}
			//İstek handler'ını çağır
			vc := reflect.New(route.controllerType)
			init := vc.MethodByName("Init")
			in := make([]reflect.Value, 2)
			ct := &Context{ResponseWriter: w, Request: r, Params: params}
			in[0] = reflect.ValueOf(ct)
			in[1] = reflect.ValueOf(route.controllerType.Name())
			init.Call(in)
			in = make([]reflect.Value, 0)
			method := vc.MethodByName("Prepare")
			method.Call(in)
			if r.Method == "GET" {
				method = vc.MethodByName("Get")
				method.Call(in)
			} else if r.Method == "POST" {
				method = vc.MethodByName("Post")
				method.Call(in)
			} else if r.Method == "HEAD" {
				method = vc.MethodByName("Head")
				method.Call(in)
			} else if r.Method == "DELETE" {
				method = vc.MethodByName("Delete")
				method.Call(in)
			} else if r.Method == "PUT" {
				method = vc.MethodByName("Put")
				method.Call(in)
			} else if r.Method == "PATCH" {
				method = vc.MethodByName("Patch")
				method.Call(in)
			} else if r.Method == "OPTIONS" {
				method = vc.MethodByName("Options")
				method.Call(in)
			}
			if AutoRender {
				method = vc.MethodByName("Render")
				method.Call(in)
			}
			method = vc.MethodByName("Finish")
			method.Call(in)
			started = true
			break
		}
	
		//url ile eşleşme yoksa, bulunamadı hatası fırlat
		if started == false {
			http.NotFound(w, r)
		}
	}

### Başlarken

Yönlendirici tasarımımızı kullanarak, daha önce bahsedilen üç sınırlamayı çözebiliriz. Üç ana kullanım senaryosu şunlardır:

Rota handler'larını kaydetme:

	beego.BeeApp.RegisterController("/", &controllers.MainController{})

Dinamik parametreleri ele alma:

	beego.BeeApp.RegisterController("/:param", &controllers.UserController{})

Regex eşleştirme:

	beego.BeeApp.RegisterController("/users/:uid([0-9]+)", &controllers.UserController{})

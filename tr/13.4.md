# 13.4 Loglar ve yapılandırmalar

## Loglamanın ve yapılandırmanın önemi

Kitapta daha önce, olay loglamanın uygulama geliştirmede çok önemli bir rol oynadığını görmüştük. Yeterli loglama ile, daha sonra hata ayıklama ve optimizasyon amacıyla incelenebilecek kritik bilgileri kaydedebiliriz. seelog loglama aracına baktığımız bölümde, çeşitli log seviyesi kademeleri için ayarlar bulunduğunu görmüştük; bunlar program geliştirme ve yayınlama için gerekli olabilir: geliştirme ortamında loglama seviyesini düşük tutarken, uygulamamızda hata ayıklamaya çalışırken gereksiz bilgileri gizleyebilmek için üretim ortamında bu seviyeyi yüksek tutabiliriz.

Bir uygulamayı yayınlamak için sunucu yapılandırma modülünü kurmak, bir dizi farklı sunucu ayarını içerir. Örneğin, genellikle veritabanı yapılandırması, dinleme portları vb. bilgileri yapılandırma dosyası aracılığıyla sağlamamız gerekir. Merkezi bir yapılandırma dosyası kurmak, uygulamayı farklı makinelere dağıtma ve gerektiğinde uzak veritabanlarına bağlanma esnekliği sağlar.

## Beego loglama sistemi

Beego logger'ının tasarımı seelog'dan fikirler ödünç alır ve loglama seviyelerini ayarlama açısından benzer bir işlevsellik sunar. Ancak Beego'nun sistemi daha hafiftir ve Go'nun `log.Logger` interface'ini kullanır. Öntanımlı olarak loglar os.Stdout'a çıktılanır, ancak kullanıcılar bunu özelleştirmek için `beego.SetLogger` aracılığıyla bu interface'i implemente edebilir. Implemente edilmiş bir interface'in detaylı bir örneği aşağıda görülebilir:

	// Log levels for controlling the logging output.
	const (
		LevelTrace = iota
		LevelDebug
		LevelInfo
		LevelWarning
		LevelError
		LevelCritical
	)
	
	// logLevel controls the global log level used by the logger.
	var level = LevelTrace
	
	// LogLevel returns the global log level and can be used in
	// a custom implementations of the logger interface.
	func Level() int {
		return level
	}
	
	// SetLogLevel sets the global log level used by the simple
	// logger.
	func SetLevel(l int) {
		level = l
	}
	
Bu bölüm yukarıdaki log kademelendirme sistemini implemente eder. Öntanımlı seviye Trace olarak ayarlanmıştır ve kullanıcılar `SetLevel` kullanarak kademelendirme seviyelerini özelleştirebilir.

	// logger references the used application logger.
	var BeeLogger = log.New(os.Stdout, "", log.Ldate|log.Ltime)
	
	// SetLogger sets a new logger.
	func SetLogger(l *log.Logger) {
		BeeLogger = l
	}
	
	// Trace logs a message at trace level.
	func Trace(v ...interface{}) {
		if level <= LevelTrace {
			BeeLogger.Printf("[T] %v\n", v)
		}
	}
	
	// Debug logs a message at debug level.
	func Debug(v ...interface{}) {
		if level <= LevelDebug {
			BeeLogger.Printf("[D] %v\n", v)
		}
	}
	
	// Info logs a message at info level.
	func Info(v ...interface{}) {
		if level <= LevelInfo {
			BeeLogger.Printf("[I] %v\n", v)
		}
	}
	
	// Warning logs a message at warning level.
	func Warn(v ...interface{}) {
		if level <= LevelWarning {
			BeeLogger.Printf("[W] %v\n", v)
		}
	}
	
	// Error logs a message at error level.
	func Error(v ...interface{}) {
		if level <= LevelError {
			BeeLogger.Printf("[E] %v\n", v)
		}
	}
	
	// Critical logs a message at critical level.
	func Critical(v ...interface{}) {
		if level <= LevelCritical {
			BeeLogger.Printf("[C] %v\n", v)
		}
	}

Yukarıdaki kod parçası, öntanımlı olarak logları `os.Stdout`'a çıktılayan bir `BeeLogger` nesnesini ilklendirir. Belirtildiği gibi, kullanıcılar logger'ın çıktısını özelleştirmek için `beego.SetLogger`'ı implemente edebilir. `BeeLogger` altı fonksiyon implemente eder:

- Trace (genel bilgi kaydeder, örneğin:)
	- "Entered parse function validation block"
	- "Validation: entered second 'if'"
	- "Dictionary 'Dict' is empty. Using default value"
- Debug (hata ayıklama bilgisi, örneğin:)
	- "Web page requested: http://somesite.com Params = '...'"
	- "Response generated. Response size: 10000. Sending."
	- "New file received. Type: PNG Size: 20000"
- Info (genel bilgi basar, örneğin:)
	- "Web server restarted"
	- "Hourly statistics: Requested pages: 12345 Errors: 123..."
	- "Service paused. Waiting for 'resume' call"
- Warn (uyarı mesajları, örneğin:)
	- "Cache corrupted for file = 'test.file'. Reading from back-end"
	- "Database 192.168.0.7/DB not responding. Using backup 192.168.0.8/DB"
	- "No response from statistics server. Statistics not sent"
- Error (hata mesajları, örneğin:)
	- "Internal error. Cannot process request# 12345 Error:...."
	- "Cannot perform login: credentials DB not responding"
- Critical (ölümcül hatalar, örneğin:)
	- "Critical panic received:.... Shutting down"
	- "Fatal error:... App is shutting down to prevent data corruption or loss"

Görebileceğiniz gibi, bu seviyelerin her birinin belirli bir amacı vardır. Örneğin, yayınlama sırasında loglama seviyesini Warn (`level=LevelWarning`) olarak ayarlarsak, daha düşük seviyedeki tüm loglar (Trace, Debug, Info) hiçbir çıktı üretmeyecektir.

## Beego yapılandırma tasarımı

Yapılandırma bilgisini işlemek için Beego, `ini` yapılandırma dosyalarına benzer biçimlendirilmiş bilgiyi okuyan bir key=value dosya ayrıştırıcısı implemente eder. Ayrıştırıcı, yapılandırma verisini okur ve bir map'e kaydeder. Son olarak, değerin veri tipini (int, string, vb.) almak için çeşitli fonksiyonları çağırır. Detaylı implementasyon aşağıda görülebilir:

`ini` yapılandırma dosyası için bazı global sabitler tanımlayalım:

	var (
		bComment = []byte{'#'}
		bEmpty   = []byte{}
		bEqual   = []byte{'='}
		bDQuote  = []byte{'"'}
	)

Yapılandırma dosyasının biçimini tanımlar:

	// A Config represents the configuration.
	type Config struct {
		filename string
		comment  map[int][]string  // id: []{comment, key...}; id 1 is for main comment.
		data     map[string]string // key: value
		offset   map[string]int64  // key: offset; for editing.
		sync.RWMutex
	}
	

Dosyayı ayrıştıran bir fonksiyon tanımlar. Süreç dosyayı açarak başlar, ardından satır satır okuyup yorumları, boş satırları ve key=value verisini ayrıştırır:
	
	// ParseFile creates a new Config and parses the file configuration from the
	// named file.
	func LoadConfig(name string) (*Config, error) {
		file, err := os.Open(name)
		if err != nil {
			return nil, err
		}
	
		cfg := &Config{
			file.Name(),
			make(map[int][]string),
			make(map[string]string),
			make(map[string]int64),
			sync.RWMutex{},
		}
		cfg.Lock()
		defer cfg.Unlock()
		defer file.Close()
	
		var comment bytes.Buffer
		buf := bufio.NewReader(file)
	
		for nComment, off := 0, int64(1); ; {
			line, _, err := buf.ReadLine()
			if err == io.EOF {
				break
			}
			if bytes.Equal(line, bEmpty) {
				continue
			}
	
			off += int64(len(line))
	
			if bytes.HasPrefix(line, bComment) {
				line = bytes.TrimLeft(line, "#")
				line = bytes.TrimLeftFunc(line, unicode.IsSpace)
				comment.Write(line)
				comment.WriteByte('\n')
				continue
			}
			if comment.Len() != 0 {
				cfg.comment[nComment] = []string{comment.String()}
				comment.Reset()
				nComment++
			}
	
			val := bytes.SplitN(line, bEqual, 2)
			if bytes.HasPrefix(val[1], bDQuote) {
				val[1] = bytes.Trim(val[1], `"`)
			}
	
			key := strings.TrimSpace(string(val[0]))
			cfg.comment[nComment-1] = append(cfg.comment[nComment-1], key)
			cfg.data[key] = strings.TrimSpace(string(val[1]))
			cfg.offset[key] = off
		}
		return cfg, nil
	}

Aşağıda, ayrıştırıcının yapılandırma dosyasını okumak için kullandığı bir dizi fonksiyon bulunmaktadır. Dönüş değeri bool, int, float64 veya string olarak belirlenir:

	// Bool returns the boolean value for a given key.
	func (c *Config) Bool(key string) (bool, error) {
		return strconv.ParseBool(c.data[key])
	}
	
	// Int returns the integer value for a given key.
	func (c *Config) Int(key string) (int, error) {
		return strconv.Atoi(c.data[key])
	}
	
	// Float returns the float value for a given key.
	func (c *Config) Float(key string) (float64, error) {
		return strconv.ParseFloat(c.data[key], 64)
	}
	
	// String returns the string value for a given key.
	func (c *Config) String(key string) string {
		return c.data[key]
	}

## Uygulama kılavuzu

Aşağıdaki fonksiyon, uzak bir url adresinden json verisi almak için kullandığım bir uygulama örneğidir:

	func GetJson() {
		resp, err := http.Get(beego.AppConfig.String("url"))
		if err != nil {
			beego.Critical("http get info error")
			return
		}
		defer resp.Body.Close()
		body, err := ioutil.ReadAll(resp.Body)
		err = json.Unmarshal(body, &AllInfo)
		if err != nil {
			beego.Critical("error:", err)
		}
	}

`GetJson()` fonksiyonunda meydana gelebilecek herhangi bir hatayı bildirmek için Beego'nun `Critical()` loglama fonksiyonu çağrılır. `beego.AppConfig.String("url")`, bir yapılandırma dosyasından (genellikle `app.conf`) bilgi almak için kullanılır; bu dosya aşağıdakine benzer bir şey olabilir:

	appname = hs
	url ="http://www.api.com/api.html"

# 13.5 Blog ekleme, silme ve güncelleme

Beego çatısının arkasındaki tüm kavramı örnekler ve sözde kod aracılığıyla zaten tanıttık. Bu bölümde, blog yazılarını görüntüleme, ekleme, değiştirme ve silme yeteneği dahil olmak üzere Beego kullanarak bir blog sisteminin nasıl uygulanacağı anlatılacaktır.

## Blog dizini

Blogumuzun dizin yapısı aşağıda görülebilir:

```
/main.go
/views:
    /view.tpl
    /new.tpl
    /layout.tpl
    /index.tpl
    /edit.tpl
/models/model.go
/controllers:
    /index.go
	/view.go
	/new.go
	/delete.go
	/edit.go	
```


## Blog yönlendirmesi

Blogumuzun ana yönlendirme kuralları şu şekildedir:

```
//Blog anasayfasını göster
beego.RegisterController("/", &controllers.IndexController{})
//Blog detaylarını görüntüle
beego.RegisterController("/view/: id([0-9]+)", &controllers.ViewController{})
//Blog yazısı oluştur
beego.RegisterController("/new", &controllers.NewController{})
//Yazıyı sil
beego.RegisterController("/delete/: id([0-9]+)", &controllers.DeleteController{})
//Yazıyı düzenle
beego.RegisterController("/edit/: id([0-9]+)", &controllers.EditController{})
```


## Veritabanı yapısı

Temel blog bilgilerini saklamak için basit bir veritabanı tablosu:

```
CREATE TABLE entries (
    id INT AUTO_INCREMENT,
    title TEXT,
    content TEXT,
    created DATETIME,
    primary key (id)
);
```

NewController


```
type NewController struct {
	beego.Controller
}

func (this *NewController) Get() {
	this.Layout = "layout.tpl"
	this.TplNames = "new.tpl"
}

func (this *NewController) Post() {
	inputs := this.Input()
	var blog models.Blog
	blog.Title = inputs.Get("title")
	blog.Content = inputs.Get("content")
	blog.Created = time.Now()
	models.SaveBlog(blog)
	this.Ctx.Redirect(302, "/")
}
```

DeleteController

```

	beego.Controller
```

## Model katmanı

```
package models

import (
	"database/sql"
	"github.com/astaxie/beedb"
	_ "github.com/ziutek/mymysql/godrv"
	"time"
)

type Blog struct {
	Id      int `PK`
	Title   string
	Content string
	Created time.Time
}

func GetLink() beedb.Model {
	db, err := sql.Open("mymysql", "blog/astaxie/123456")
	if err != nil {
		panic(err)
	}
	orm := beedb.New(db)
	return orm
}

func GetAll() (blogs []Blog) {
	db := GetLink()
	db.FindAll(&blogs)
	return
}

func GetBlog(id int) (blog Blog) {
	db := GetLink()
	db.Where("id=?", id).Find(&blog)
	return
}

func SaveBlog(blog Blog) (bg Blog) {
	db := GetLink()
	db.Save(&blog)
	return bg
}

func DelBlog(blog Blog) {
	db := GetLink()
	db.Delete(&blog)
	return
}
```

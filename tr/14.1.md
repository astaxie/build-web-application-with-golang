# 14.1 Statik dosyalar

Önceki bölümlerde statik dosyalarla nasıl çalışılacağından daha önce bahsetmiştik. Şimdi, Beego içinde statik dosyaların nasıl kurulup kullanılacağına bakalım. Ardından, Twitter'ın açık kaynaklı HTML ve CSS çatısı Bootstrap'i tanıtarak, fazla tasarım işi yapmadan hızlıca güzel görünümlü web siteleri oluşturabileceğiz.

## Beego statik dosyaları ve ayarları

Go'nun `net/http` paketi, `ServeFile` ve `FileServer` gibi fonksiyonlarla bir statik dosya sunucusu sağlar. Beego'nun statik dosya işleme mekanizması bu katmana dayanır ve somut uygulaması şu şekildedir:

	//static file server
	for prefix, staticDir := range StaticDir {
		if strings.HasPrefix(r.URL.Path, prefix) {
			file := staticDir + r.URL.Path[len(prefix):]
			http.ServeFile(w, r, file)
			w.started = true
			return
		}
	}

`StaticDir`, bir statik dosya dizinine karşılık gelen URL'yi saklar; bu yüzden istekleri işlerken sadece URL'nin bir statik dosya yoluyla başlayıp başlamadığını belirlememiz yeterlidir. Eğer başlıyorsa, `http.ServeFile` kullanarak basitçe yanıt verebiliriz.

Aşağıda bir örnek verilmiştir:

	beego.StaticDir["/asset"] = "/static"

Bu durumda, `http://www.beego.me/asset/bootstrap.css` gibi bir URL ile gelen istek, istemciye `/static/bootstrap.css` dosyasının sunulmasıyla sonuçlanır.

## Bootstrap entegrasyonu

Bootstrap, Twitter tarafından hayata geçirilmiş, ön yüz geliştirme için açık kaynaklı bir araç setidir. Geliştiriciler için Bootstrap, hızlı Web uygulaması geliştirme adına en iyi ön yüz kitlerinden biridir. En güncel HTML5 standartlarını kullanan HTML, CSS ve javascript bileşenlerinden oluşan bir koleksiyondur. Bunlar arasında duyarlı (responsive) bir grid, formlar, butonlar, tablolar ve daha birçok kullanışlı öğe bulunur.

- Bileşenler
Bootstrap, zengin bir Web bileşenleri koleksiyonu içerir. Bu bileşenleri kullanarak, aşağıdaki bileşenleri içeren güzel görünümlü ve tam işlevsel bir web sitesini hızlıca oluşturabilirsiniz:
Açılır menüler, buton grupları, buton açılır menüleri, gezinme, gezinme çubukları, ekmek kırıntıları (breadcrumb), sayfalama, düzen (layout), küçük resimler (thumbnail), uyarı diyalogları, ilerleme çubukları ve diğer medya nesneleri
- JavaScript eklentileri
Bootstrap, Bootstrap bileşenlerine "hayat" veren 13 jQuery eklentisiyle birlikte gelir. Bunlar arasında şunlar bulunur:
Modal diyaloglar, sekmeler, kaydırma çubukları, açılır kutular ve benzerleri.
- Bootstrap çatısını özelleştirme
Tüm Bootstrap css değişkenleri ihtiyaçlarınıza göre değiştirilebilir.

	![](images/14.1.bootstrap2.png?raw=true)
	
	Şekil 14.2 Proje statik dosya dizin yapısı

2. Beego, `StaticDir` için varsayılan bir değer ayarladığından, statik dosyalar dizininiz `static` ise başka bir şey yapmanıza gerek yoktur:

	StaticDir["/static"] = "static"

3. Şablonlarımız aşağıdaki varlık (asset) yollarını kullanır:

		// css file
		<link href="/static/css/bootstrap.css" rel="stylesheet">

		// js file
		<script src="/static/js/bootstrap-transition.js"></script>

		// Picture files
		<img src="/static/img/logo.png">

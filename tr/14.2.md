# 14.2 Session

6. bölümde Go'da session'lara ilişkin bazı temel kavramları tanıtmış ve bir session yöneticisi geliştirmiştik. Beego çatısı, bazı kullanışlı session işleme işlevlerini gerçekleştirmek için bu session yöneticisini kullanır.

## Session'ları entegre etme

Beego, session'ları esas olarak aşağıdaki global değişkenlere göre işler:

	// session ile ilgili
	SessionOn bool	// session modülünün açılıp açılmayacağı. Öntanımlı değer false
	SessionProvider string	// istenen session arka uç işleme modülü. Öntanımlı olarak bellek içi sessionManager
	SessionName string	// istemcide saklanan çerezlerin adı
	SessionGCMaxLifetime int64	// çerez geçerlilik süresi

	GlobalSessions *session.Manager// global session denetleyicisi

Elbette, yukarıda gösterilen bu değişkenlerin değerlerinin ilklendirilmesi gerekir. Bu değerleri ayarlamak için aşağıdaki yapılandırma dosyası kodundaki değerleri de kullanabilirsiniz:

	if ar, err := AppConfig.Bool("sessionon"); err != nil {
		SessionOn = false
	} else {
		SessionOn = ar
	}
	if ar := AppConfig.String("sessionprovider"); ar == "" {
		SessionProvider = "memory"
	} else {
		SessionProvider = ar
	}
	if ar := AppConfig.String("sessionname"); ar == "" {
		SessionName = "beegosessionID"
	} else {
		SessionName = ar
	}
	if ar, err := AppConfig.Int("sessiongcmaxlifetime"); err != nil && ar != 0 {
		int64val, _ := strconv.ParseInt(strconv.Itoa(ar), 10, 64)
		SessionGCMaxLifetime = int64val
	} else {
		SessionGCMaxLifetime = 3600
	}

`beego.Run` fonksiyonuna aşağıdaki kodu ekleyin:

	if SessionOn {
		GlobalSessions, _ = session.NewManager(SessionProvider, SessionName, SessionGCMaxLifetime)
		go GlobalSessions.GC()
	}

`SessionOn` true olarak ayarlandığı sürece, öntanımlı olarak bağımsız bir goroutine session işleyicisiyle session'ı açacaktır

Özel Controller'ımızın session'ı hızlıca kullanmasını kolaylaştırmak için, yazar `beego.Controller` üzerinde aşağıdaki methodları sağlar:

Özel bir Controller'da session'ları hızlıca kullanmamıza yardımcı olmak için `beego.Controller` aşağıdaki methodu sağlar:

	func (c *Controller) StartSession() (sess session.Session) {
		sess = GlobalSessions.SessionStart(c.Ctx.ResponseWriter, c.Ctx.Request)
		return
	}		

## Session'ları kullanma 

Yukarıdaki koddan, Beego çatısının session işlevselliğini basitçe miras aldığını görebiliriz. Peki, bunu projelerimizde nasıl kullanırız?

Öncelikle, uygulamamızın başlangıç noktasında session'ı açmamız gerekir.

	beego.SessionOn = true

Ardından controller'ımızın içinde ilgili session methodunu şu şekilde kullanabiliriz:

	func (this *MainController) Get() {
		var intcount int
		sess := this.StartSession()
		count := sess.Get("count")
		if count == nil {
			intcount = 0
		} else {
			intcount = count.(int)
		}
		intcount = intcount + 1
		sess.Set("count", intcount)
		this.Data["Username"] = "astaxie"
		this.Data["Email"] = "astaxie@gmail.com"
		this.Data["Count"] = intcount
		this.TplNames = "index.tpl"
	}

Yukarıdaki kod, session'ların controller mantığında nasıl kullanılacağını gösterir. Süreç iki adıma ayrılabilir:

1. Session nesnesini alma

		// Nesneyi al, PHP'deki session_start() işlevine benzer
		sess:= this.StartSession()

2. Session'ı genel işlemler için kullanma

		// Session değerlerini al, PHP'deki $ _SESSION ["count"] işlevine benzer
		sess.Get("count")
		
		// Session değerini ayarla
		sess.Set("count", intcount)

Görebildiğiniz gibi, Beego çatısına dayanan uygulamalar session'ları kolayca gerçekleştirebilir. Bu süreç, PHP uygulamalarında `session_start()` çağırmaya çok benzer.

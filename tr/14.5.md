# 14.5 Çoklu dil desteği

Uluslararasılaştırma ve yerelleştirmeyi tanıttığımız bölümde `go-i18n` kütüphanesini geliştirmiştik. Bu bölümde, bu kütüphanenin Beego çatısına nasıl entegre edildiğini ve Beego uygulamalarımızın hem uluslararasılaştırmayı hem de yerelleştirmeyi desteklemesini nasıl sağladığını göreceğiz.

## I18n entegrasyonu

Beego önce bazı global değişkenler tanımlar:

	Translation i18n.IL
	Lang string // dil paketini ayarlar, zh, en
	LangPath string // dil paketinin konumunu ayarlar

Bir çoklu dil ilklendirme fonksiyonu tanımlanır:

	func InitLang(){
		beego.Translation:=i18n.NewLocale()
		beego.Translation.LoadPath(beego.LangPath)
		beego.Translation.SetLocale(beego.Lang)
	}

Şablon paketinde çoklu dil çağrılarını doğrudan kolaylaştırmak için, çoklu dil yanıtlarını işlemek üzere üç fonksiyon tasarladık:

	beegoTplFuncMap["Trans"] = i18n.I18nT
	beegoTplFuncMap["TransDate"] = i18n.I18nTimeDate
	beegoTplFuncMap["TransMoney"] = i18n.I18nMoney
	
	func I18nT(args ...interface{}) string {
	    ok := false
	    var s string
	    if len(args) == 1 {
	        s, ok = args[0].(string)
	    }
	    if !ok {
	        s = fmt.Sprint(args...)
	    }
	    return beego.Translation.Translate(s)
	}
	
	func I18nTimeDate(args ...interface{}) string {
	    ok := false
	    var s string
	    if len(args) == 1 {
	        s, ok = args[0].(string)
	    }
	    if !ok {
	        s = fmt.Sprint(args...)
	    }
	    return beego.Translation.Time(s)
	}	
	
	func I18nMoney(args ...interface{}) string {
	    ok := false
	    var s string
	    if len(args) == 1 {
	        s, ok = args[0].(string)
	    }
	    if !ok {
	        s = fmt.Sprint(args...)
	    }
	    return beego.Translation.Money(s)
	}

## Çoklu dil geliştirme

1. Dili ve dil paketinin konumunu ayarlayın, ardından i18n nesnelerini ilklendirin:

		beego.Lang = "zh"
		beego.LangPath = "views/lang"
		beego.InitLang()

2. Çoklu dil paketi tasarlamak

  Yukarıda, çoklu dil paketinin nasıl ilklendirileceğinden bahsettik. Şimdi, bir tanesinin nasıl tasarlanacağına bakalım. Çoklu dil paketleri, 10. Bölüm'de zaten gördüğünüz gibi, tipik olarak JSON dosyalarıdır. Desteklemek istediğimiz diller için `LangPath` üzerinde çeviri dosyaları sağlamalıyız, örneğin aşağıdaki gibi:

		# zh.json
	
		{
		"zh": {
		    "submit": "提交",
		    "create": "创建"
		    }
		}
		
		# en.json
		
		{
		"en": {
		    "submit": "Submit",
		    "create": "Create"
		    }
		}

3. Dil paketlerini kullanmak

	Controller'ı çağırarak istenen dilde çevrilmiş yanıtı şu şekilde alabiliriz:

		func (this *MainController) Get() {
			this.Data["create"] = beego.Translation.Translate("create")
			this.TplNames = "index.tpl"
		}

	Çevrilmiş yanıtları şablonlarımıza doğrudan da yerleştirebiliriz:

		// Doğrudan metin çevirisi
		{{.create | Trans}}

		// Tarih çevirisi
		{{.time | TransDate}}

		// Para birimi çevirisi
		{{.money | TransMoney}}

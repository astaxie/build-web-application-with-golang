# 14.6 pprof

Go standart kütüphanesinin harika özelliklerinden biri kod performansı izleme araçlarıdır. Bu paketler iki yerde bulunur:

	net/http/pprof
	
	runtime/pprof

Aslında `net/http/pprof`, `runtime/pprof` paketindeki çalışma zamanı profil verilerini bir HTTP portu üzerinden basitçe dışarı açar.

## Beego'da pprof desteği

Beego çatısı şu anda pprof'u destekliyor, ancak varsayılan olarak açık değildir. Uygulamanızın performansını test etmeniz gerekiyorsa (örneğin çalışan goroutine'i görüntüleyerek) Go'nun varsayılan paketi "net/http/pprof" bu özelliğe zaten sahiptir. Beego, ServHTTP fonksiyonunu yeniden paketlediği için pprof içinde yer alan varsayılan özelliği açamazsınız. Bu nedenle beego, pprof'u dahili olarak desteklemektedir.

- Öncelikle `beego.Run` fonksiyonumuzda, yapılandırma değişkenimize göre (bu durumda PprofOn) performans paketini otomatik olarak yükleyip yüklemeyeceğimizi seçiyoruz:

		if PprofOn {
			BeeApp.RegisterController(`/debug/pprof`, &ProfController{})
			BeeApp.RegisterController(`/debug/pprof/:pp([\w]+)`, &ProfController{})
		}

- `ProfController`'ı tasarlamak

		package beego

		import (
			"net/http/pprof"
		)
		
		type ProfController struct {
			Controller
		}
		
		func (this *ProfController) Get() {
			switch this.Ctx.Params[":pp"] {
			default:
				pprof.Index(this.Ctx.ResponseWriter, this.Ctx.Request)
			case "":
				pprof.Index(this.Ctx.ResponseWriter, this.Ctx.Request)
			case "cmdline":
				pprof.Cmdline(this.Ctx.ResponseWriter, this.Ctx.Request)
			case "profile":
				pprof.Profile(this.Ctx.ResponseWriter, this.Ctx.Request)
			case "symbol":
				pprof.Symbol(this.Ctx.ResponseWriter, this.Ctx.Request)
			}
			this.Ctx.ResponseWriter.WriteHeader(200)
		}


## Başlarken

Yukarıdakilerden görebileceğimiz gibi, pprof'u etkinleştirmek `PprofOn` yapılandırma değişkenini `true` olarak ayarlamak kadar basittir:

	beego.PprofOn = true
